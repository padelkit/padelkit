# FrameState

`FrameState` is a frozen dataclass storing a complete synchronized snapshot of the court at timestamp `t`: 9D ball state, up to four [`PlayerPose`](/player-pose) actors (`"P1"`–`"P4"`), optional event tags, and full scoreboard state. Import via `from padelkit import FrameState`. {{ className: 'lead' }}

Sequences of `FrameState` objects populate a [`MatchTimeline`](/match-timeline) or stream directly to [`PadelVisualizer.push_frame()`](/padel-visualizer#push-frame-and-stop-server).

## Parameters & Fields {{ tag: 'dataclass', label: 'FrameState' }}

<Row>
  <Col>

    <Properties>
      <Property name="timestamp" type="float">
        Elapsed timeline time in seconds (`>= 0.0`).
      </Property>
      <Property name="ball_position" type="tuple[float, float, float]">
        3D ball center position `(x, y, z)` in centered court meters.
      </Property>
      <Property name="ball_velocity" type="tuple[float, float, float]">
        3D linear ball velocity `(vx, vy, vz)` in `m/s`. Defaults to `(0.0, 0.0, 0.0)`.
      </Property>
      <Property name="ball_spin" type="tuple[float, float, float]">
        3D angular ball spin `(wx, wy, wz)` in `rad/s`. Defaults to `(0.0, 0.0, 0.0)`.
      </Property>
      <Property name="players" type="dict[str, PlayerPose]">
        Dictionary keyed by player slot (`"P1"`, `"P2"`, `"P3"`, `"P4"`) mapping to [`PlayerPose`](/player-pose). Defaults to empty dict `{}`.
      </Property>
      <Property name="score" type="str">
        Formatted HUD scoreboard label. Defaults to `"0-0 | 0-0"`.
      </Property>
      <Property name="event" type="str | None">
        Optional frame tag (e.g. `"serve"`, `"bounce_floor"`, `"shot_bandeja"`, `"point"`). Defaults to `None`.
      </Property>
      <Property name="sets_a" type="int">
        Completed sets won by Team A. Defaults to `0`.
      </Property>
      <Property name="sets_b" type="int">
        Completed sets won by Team B. Defaults to `0`.
      </Property>
      <Property name="games_a" type="int">
        Games won by Team A in the active set. Defaults to `0`.
      </Property>
      <Property name="games_b" type="int">
        Games won by Team B in the active set. Defaults to `0`.
      </Property>
      <Property name="points_a" type="str">
        Game point call for Team A (`"0"`, `"15"`, `"30"`, `"40"`, `"AD"`, or tiebreak integer string). Defaults to `"0"`.
      </Property>
      <Property name="points_b" type="str">
        Game point call for Team B (`"0"`, `"15"`, `"30"`, `"40"`, `"AD"`, or tiebreak integer string). Defaults to `"0"`.
      </Property>
      <Property name="server_team" type="str | None">
        Active serving team (`"A"`, `"B"`, or `None`). Defaults to `None`.
      </Property>
      <Property name="server_player" type="str | None">
        Name or ID of the active server, or `None`. Defaults to `None`.
      </Property>
      <Property name="point_index" type="int">
        Chronological rally/point index in the match (`0`-based). Defaults to `0`.
      </Property>
      <Property name="in_tiebreak" type="bool">
        `True` during a regular tiebreak or super-tiebreak. Defaults to `False`.
      </Property>
      <Property name="is_gold_point" type="bool">
        `True` when `40-40` Golden Point is active. Defaults to `False`.
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Initialization" tag="dataclass" label="FrameState">

    ```python
    from padelkit import FrameState, PlayerPose

    frame = FrameState(
        timestamp=0.5,
        ball_position=(0.2, 2.5, 1.4),
        ball_velocity=(1.0, 14.0, -1.5),
        ball_spin=(-120.0, 0.0, 0.0),
        players={
            "P1": PlayerPose("P1", x=-2.0, y=-6.0, yaw_deg=0.0, animation="shot_bandeja"),
            "P3": PlayerPose("P3", x=1.5, y=7.5, yaw_deg=180.0, animation="idle"),
        },
        event="shot_bandeja",
    )
    print(f"Speed: {frame.ball_speed_kmh:.1f} km/h | Spin: {frame.ball_spin_rpm:.0f} RPM")
    ```

## `with_match_score()` {{ tag: 'method', label: 'frame.with_match_score()' }}

<Row>
  <Col>

    Returns a new `FrameState` copy enriched cleanly from a [`MatchScore`](/match-score) snapshot, updating `score`, `sets_a..points_b`, `server_team`, `server_player`, `point_index`, `in_tiebreak`, and `is_gold_point` automatically.

    ### Arguments
    <Properties>
      <Property name="match_score" type="MatchScore">
        Source score snapshot from `match.history.get_current_score()`.
      </Property>
      <Property name="point_index" type="int">
        Point index to attach. Defaults to `0`.
      </Property>
      <Property name="server_team" type="str | None">
        Optional manual override for serving team (`"A"` / `"B"`).
      </Property>
      <Property name="server_player" type="str | None">
        Optional manual override for server player name.
      </Property>
      <Property name="golden_point_enabled" type="bool">
        Sets `is_gold_point=True` when at `40-40` even if `match_score.is_gold_point` was unset. Defaults to `False`.
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Attach MatchScore to Frame" tag="method" label="with_match_score">

    ```python
    from padelkit import FrameState, Match, TeamId

    match = Match(advantage_method="gold_point")
    score = match.history.add_point(TeamId.A)

    frame = FrameState(timestamp=1.0, ball_position=(0.0, 0.0, 1.0))
    enriched = frame.with_match_score(score, point_index=1)
    print(enriched.score, "| Server:", enriched.server_team)
    ```

    </CodeGroup>

  </Col>
</Row>

## `to_dict()` {{ tag: 'method', label: 'frame.to_dict()' }}

<Row>
  <Col>

    Serializes the snapshot into the compact JSON payload expected by the Three.js studio and `/events` live SSE stream (`t`, `ball`, `ball_vel`, `ball_spin`, `ball_speed_kmh`, `ball_spin_rpm`, `players`, `score`, `sets_a..is_gold_point`, `event`).

  </Col>
  <Col sticky>

    <CodeGroup title="Serialize Frame JSON" tag="method" label="to_dict">

    ```python
    from padelkit import FrameState

    f = FrameState(timestamp=0.25, ball_position=(0.0, 1.0, 1.2))
    print(f.to_dict()["t"], f.to_dict()["ball"])
    ```

    </CodeGroup>

  </Col>
</Row>
