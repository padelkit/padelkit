# BallPhysicsEngine

`BallPhysicsEngine` is the 9-Dimensional (`9D`) aerodynamic and multi-surface collision simulator in PadelKit. It integrates gravity, ambient wind, felt-weighted quadratic drag, and non-linear Spindt Magnus spin lift via **4th-order Runge–Kutta (`RK4`)**, resolving analytical Coulomb `SLIDING` vs `ROLLING` bounces against the court floor, walls, glass, metallic mesh, doorways, optional indoor ceiling, and center net. Import via `from padelkit import BallPhysicsEngine`. {{ className: 'lead' }}

## Parameters & Fields {{ tag: 'dataclass', label: 'BallPhysicsEngine' }}

<Row>
  <Col>

    `BallPhysicsEngine` can be instantiated with zero arguments to simulate standard FIP indoor conditions, or customized per-venue:

    <Properties>
      <Property name="court" type="Court">
        [`Court`](/court) geometry defining wall positions, stepped/uniform side enclosure heights, open or closed doorways, and optional indoor `ceiling_height`. Defaults to `Court.fip_standard()`.
      </Property>
      <Property name="ball" type="BallProperties">
        Ball mass, radius, moment of inertia, felt `fuzz_factor`, and COR multiplier. Defaults to `BallProperties.fip_standard()`. See [`BallProperties`](/ball-properties).
      </Property>
      <Property name="environment" type="EnvironmentConditions">
        Gravity, air density `rho`, 3D ambient wind vector, and spin decay rate. Defaults to `EnvironmentConditions.standard()`. See [`EnvironmentConditions`](/environment-conditions).
      </Property>
      <Property name="surfaces" type="SurfaceMaterials">
        Restitution (`cor`) and Coulomb friction (`mu`) across glass, masonry wall, turf floor, wire fence, and net. Defaults to `SurfaceMaterials.fip_standard()`. See [`SurfaceMaterials`](/surface-materials).
      </Property>
      <Property name="coordinate_system" type="CoordinateSystem">
        World frame (`CENTERED` default or `CORNER_BASED`) applied to initial states and returned trajectories.
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Initialization" tag="dataclass" label="BallPhysicsEngine">

    ```python
    from padelkit import (
        BallPhysicsEngine,
        BallProperties,
        Court,
        EnvironmentConditions,
        SurfaceMaterials,
    )

    engine = BallPhysicsEngine(
        court=Court.fip_standard(),
        ball=BallProperties.worn(fuzz_factor=0.6),
        environment=EnvironmentConditions.from_atmosphere(altitude_m=650.0, temperature_c=24.0),
        surfaces=SurfaceMaterials.fast_indoor(),
    )
    ```

## `simulate()` {{ tag: 'method', label: 'engine.simulate()' }}

<Row>
  <Col>

    Simulates a single 3D ball trajectory over time, sampling states at `dt` steps and capturing every surface impact as a [`BounceEvent`](/bounce-event).

    ### Arguments
    <Properties>
      <Property name="initial_state" type="BallState | np.ndarray">
        Initial 9D state as a [`BallState`](/ball-state) or NumPy vector `(9,)` / `(6,)`.
      </Property>
      <Property name="duration_s" type="float">
        Maximum simulation duration in seconds (`> 0.0`). Defaults to `2.5`. *(Keyword-only alias `duration` is also accepted if passed explicitly.)*
      </Property>
      <Property name="dt" type="float">
        RK4 integration time step in seconds (`> 0.0`). Defaults to `1 / 240` (`≈ 0.00417 s`).
      </Property>
      <Property name="stop_on_second_floor_bounce" type="bool">
        When `True`, terminates early immediately upon recording the second [`SurfaceType.FLOOR`](/physics-enums#surface-type) bounce (end of live play). Defaults to `False`.
      </Property>
      <Property name="seed" type="int | None">
        Optional random seed passed to `np.random.default_rng` for deterministic stochastic bounces when `surfaces.fence_randomness > 0`. Defaults to `None`.
      </Property>
    </Properties>

    ### Returns
    <Properties>
      <Property name="trajectory" type="BallTrajectory">
        [`BallTrajectory`](/ball-trajectory) holding `timestamps`, `states`, and chronological `bounces`.
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Simulate Single Trajectory" tag="method" label="simulate">

    ```python
    from padelkit import BallPhysicsEngine, BallState

    engine = BallPhysicsEngine()
    shot = BallState.from_shot(
        position=(-2.5, -2.0, 2.3),
        velocity=(3.5, 16.0, -2.5),
        topspin_rpm=-1800.0,
    )

    traj = engine.simulate(
        shot,
        duration_s=2.5,
        dt=1 / 240,
        stop_on_second_floor_bounce=True,
    )
    print("Duration (s):", round(traj.duration_seconds, 2))
    print("Max height (m):", round(traj.max_height, 2))
    print("Bounces:", [(round(b.timestamp, 2), b.surface.value) for b in traj.bounces])
    ```

    </CodeGroup>

  </Col>
</Row>

## `simulate_batch()` {{ tag: 'method', label: 'engine.simulate_batch()' }}

<Row>
  <Col>

    Vectorized NumPy simulator advancing **`B` ball states in parallel** over `num_steps` with zero Python loop over particles—designed for 3D particle filters, RTS trajectory smoothing, and Monte Carlo rollouts.

    ### Arguments
    <Properties>
      <Property name="initial_states" type="np.ndarray">
        2D array of shape `(B, 9)` (or `(B, 6)` with zero initial spin) containing `B` initial 9D states.
      </Property>
      <Property name="num_steps" type="int">
        Exact number of RK4 steps to integrate forward.
      </Property>
      <Property name="dt" type="float">
        Fixed time step in seconds per step. Defaults to `1 / 120`.
      </Property>
    </Properties>

    ### Returns
    <Properties>
      <Property name="trajectories" type="np.ndarray">
        Single `float64` NumPy array of shape `(B, num_steps + 1, 9)` containing all `B` trajectories including initial states at index `0`.
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Vectorized Particle Rollout" tag="method" label="simulate_batch">

    ```python
    import numpy as np
    from padelkit import BallPhysicsEngine

    engine = BallPhysicsEngine()

    # 1,000 noisy particle hypotheses around an initial shot
    rng = np.random.default_rng(0)
    batch = np.zeros((1000, 9), dtype=np.float64)
    batch[:, 2] = 2.0
    batch[:, 4] = 15.0 + rng.normal(0.0, 0.5, size=1000)
    batch[:, 5] = -1.5

    # Returns array of shape (1000, 121, 9) over 1.0 s (120 steps @ 1/120 s)
    states = engine.simulate_batch(batch, num_steps=120, dt=1 / 120)
    final_xy = states[:, -1, :2]
    print("Mean final landing (X, Y):", np.round(final_xy.mean(axis=0), 2))
    ```

    </CodeGroup>

  </Col>
</Row>

## `step()` {{ tag: 'method', label: 'engine.step()' }}

<Row>
  <Col>

    Advances a single [`BallState`](/ball-state) or 9D vector by one step `dt` via `rk4_step()` and resolves collisions against the floor, side/back walls, wire fence (respecting open doorways vs overhead lintels), optional ceiling, and net.

    ### Arguments
    <Properties>
      <Property name="state" type="BallState | np.ndarray">
        Current 9D state.
      </Property>
      <Property name="dt" type="float">
        Time step in seconds. Defaults to `1 / 240`.
      </Property>
      <Property name="timestamp" type="float">
        Current timestamp in seconds (stamped onto any returned `BounceEvent` at `timestamp + dt`). Defaults to `0.0`.
      </Property>
      <Property name="rng" type="np.random.Generator | None">
        Optional NumPy RNG used when `fence_randomness > 0`.
      </Property>
    </Properties>

    ### Returns
    `tuple[BallState, BounceEvent | None]` — Next ball state and an optional [`BounceEvent`](/bounce-event) if contact occurred.

  </Col>
  <Col sticky>

    <CodeGroup title="Single-Step Loop" tag="method" label="step">

    ```python
    from padelkit import BallPhysicsEngine, BallState

    engine = BallPhysicsEngine()
    state = BallState.from_shot((0.0, -4.0, 2.0), (0.0, 14.0, -1.0))

    for i in range(60):
        state, bounce = engine.step(state, dt=1 / 240, timestamp=i / 240)
        if bounce is not None:
            print("Hit surface:", bounce.surface.value)
            break
    ```

    </CodeGroup>

  </Col>
</Row>

## `compute_acceleration()` & `rk4_step()` {{ tag: 'method', label: 'Aerodynamic Integrator' }}

<Row>
  <Col>

    Low-level aerodynamic primitives backing [`step()`](#step) and [`simulate_batch()`](#simulate-batch):

    - **`compute_acceleration(state)`**: Accepts a `BallState` or NumPy array `(9,)` / `(B, 9)` and returns `(acc_lin, acc_ang)` containing instantaneous 3D linear acceleration (`m/s²`) and angular acceleration (`rad/s²`).
    - **`rk4_step(state_vec, dt)`**: Integrates a `(9,)` or `(B, 9)` state vector forward by `dt` seconds using 4th-order Runge–Kutta free-flight dynamics (without surface collision checks).

  </Col>
  <Col sticky>

    <CodeGroup title="Free-Flight Forces & RK4" tag="method" label="compute_acceleration / rk4_step">

    ```python
    from padelkit import BallPhysicsEngine, BallState

    engine = BallPhysicsEngine()
    shot = BallState.from_shot((0.0, 0.0, 2.0), (0.0, 20.0, 0.0), topspin_rpm=2000.0)

    acc_lin, acc_ang = engine.compute_acceleration(shot)
    next_vec = engine.rk4_step(shot.vector_9d, dt=1 / 240)
    print("Vertical acceleration (m/s^2):", round(float(acc_lin[2]), 2))
    ```

    </CodeGroup>

  </Col>
</Row>

## `resolve_collision()` {{ tag: 'method', label: 'engine.resolve_collision()' }}

<Row>
  <Col>

    Analytical Coulomb **Sliding vs. Rolling** collision solver against any oriented surface plane.

    ### Arguments
    <Properties>
      <Property name="state_vec" type="np.ndarray">
        Pre-impact 9D state vector `(9,)` (`[x,y,z, vx,vy,vz, wx,wy,wz]`).
      </Property>
      <Property name="normal" type="np.ndarray">
        Unit outward normal vector `(3,)` pointing away from the surface into play (e.g. `[0, 0, 1]` for floor, `[0, -1, 0]` for far glass wall).
      </Property>
      <Property name="cor" type="float">
        Normal coefficient of restitution (`e` in `(0, 1]`).
      </Property>
      <Property name="friction" type="float">
        Tangential Coulomb friction coefficient (`mu >= 0`).
      </Property>
    </Properties>

    ### Returns
    `tuple[np.ndarray, ContactRegime]` — Updated 9D post-impact vector `(9,)` and resolved [`ContactRegime`](/physics-enums#contact-regime) (`SLIDING` or `ROLLING`).

  </Col>
  <Col sticky>

    <CodeGroup title="Custom Surface Impact" tag="method" label="resolve_collision">

    ```python
    import numpy as np
    from padelkit import BallPhysicsEngine, BallState

    engine = BallPhysicsEngine()
    pre = BallState.from_shot((0.0, 0.0, 0.033), (0.0, 15.0, -6.0), topspin_rpm=-2200.0)
    post_vec, regime = engine.resolve_collision(
        pre.vector_9d,
        normal=np.array([0.0, 0.0, 1.0]),
        cor=0.75,
        friction=0.45,
    )
    print("Regime:", regime.value, "| Post vz:", round(float(post_vec[5]), 2))
    ```

    </CodeGroup>

  </Col>
</Row>
