# Court

`Court` is the top-level geometric and venue assembly for a padel court. It pairs physical [`CourtDimensions`](/court-dimensions) with optional enclosure architecture, lateral doorways, exterior Rule 16 safety zones, indoor ceiling clearance, surface color, and geographic metadata, exposing methods to query 2D/3D landmarks, wall segments, doorway pass-through, and official FIP compliance. {{ className: 'lead' }}

Import directly with `from padelkit import Court`. By default, all coordinates are in meters under [`CoordinateSystem.CENTERED`](/court-enums#coordinate-system) (`(0, 0, 0)` at the center of the net on the floor; pass `CoordinateSystem.CORNER_BASED` to landmark methods when needed). `Court` is a frozen (immutable) dataclass.

## Parameters & Fields {{ tag: 'dataclass', label: 'Court' }}

<Row>
  <Col>

    <Properties>
      <Property name="dimensions" type="CourtDimensions">
        Physical dimensions of the playing area, lines, net, and perimeter walls in meters. Defaults to `CourtDimensions.fip_standard()`.
      </Property>
      <Property name="enclosure_type" type="EnclosureType | None">
        Solid wall material (`EnclosureType.GLASS` or `EnclosureType.WALL`). Defaults to `None` (resolved by `effective_enclosure_type` to `GLASS`).
      </Property>
      <Property name="enclosure_variant" type="EnclosureVariant | None">
        Regulatory mesh height profile along the central `16.0 m` (`V1`: `3.0 m` vs `V2`: `4.0 m`). Defaults to `None` (resolved from `dimensions.side_wall_height`).
      </Property>
      <Property name="side_wall_profile" type="SideWallProfile | None">
        End-zone solid silhouette (`0–4 m` from back corners): `STEPPED` (`3m×2m + 2m×2m`) or `UNIFORM` (`3m×4m` crystal). Defaults to `None` (`STEPPED` for masonry walls, `UNIFORM` for glass).
      </Property>
      <Property name="orientation" type="CourtOrientation | None">
        Cardinal orientation of the court's length axis (`NORTH_SOUTH` or `EAST_WEST`). Defaults to `None`.
      </Property>
      <Property name="turf_color" type="CourtSurfaceColor | str | None">
        Surface turf color (`BLUE`, `GREEN`, `TERRACOTTA`, indoor-only `BLACK`, tournament colors, or custom CSS/hex string). Defaults to `None` (`"blue"` via `effective_turf_color`).
      </Property>
      <Property name="setting" type="CourtSetting | None">
        Venue environment (`INDOOR`, `OUTDOOR`, or `SEMI_COVERED`). Defaults to `None`. Note: FIP permits `BLACK` turf only when `setting=CourtSetting.INDOOR`.
      </Property>
      <Property name="door_left" type="DoorState | None">
        Open or closed state of the left (`X = -width/2`, viewed from near side facing net) access gate. Defaults to `None` (treated as passable during play).
      </Property>
      <Property name="door_right" type="DoorState | None">
        Open or closed state of the right (`X = +width/2`) access gate. Defaults to `None`.
      </Property>
      <Property name="access_left" type="SideAccess | None">
        Doorway count and dimensions on the left sideline. Defaults to `None` (single FIP `2.0 m × 2.2 m` opening via `effective_access_left`).
      </Property>
      <Property name="access_right" type="SideAccess | None">
        Doorway count and dimensions on the right sideline. Defaults to `None` (single FIP `2.0 m × 2.2 m` opening via `effective_access_right`).
      </Property>
      <Property name="safety_zone_left" type="SafetyZone | None">
        Exterior obstacle-free clearance volume outside the left sideline for Rule 16 out-of-court play. Defaults to `None`.
      </Property>
      <Property name="safety_zone_right" type="SafetyZone | None">
        Exterior obstacle-free clearance volume outside the right sideline for Rule 16 out-of-court play. Defaults to `None`.
      </Property>
      <Property name="ceiling_height" type="float | None">
        Physical roof height in meters (`> 0.0` when set). Enables `SurfaceType.CEILING` rebounds in `BallPhysicsEngine` and is validated against the `6.0 m` FIP minimum. Defaults to `None`.
      </Property>
      <Property name="location" type="CourtLocation | None">
        Optional venue metadata (club name, city, address, country, latitude, longitude). See [`CourtLocation`](/court-location). Defaults to `None`.
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Initialization" tag="dataclass" label="Court">

    ```python
    from padelkit import (
        Court,
        CourtDimensions,
        CourtLocation,
        CourtSetting,
        CourtSurfaceColor,
        DoorState,
        EnclosureType,
        EnclosureVariant,

        SideAccess,
        SideWallProfile,
    )

    court = Court(

        enclosure_type=EnclosureType.GLASS,
        enclosure_variant=EnclosureVariant.V1,
        side_wall_profile=SideWallProfile.UNIFORM,
        turf_color=CourtSurfaceColor.BLUE,
        setting=CourtSetting.OUTDOOR,
        door_left=DoorState.OPEN,
        door_right=DoorState.OPEN,
        access_left=SideAccess.fip_dual_access(),
        access_right=SideAccess.fip_dual_access(),
        safety_zone_left=SafetyZone.fip_standard(),
        safety_zone_right=SafetyZone.fip_standard(),
        location=CourtLocation(
            club="Club de Pádel Sol",
            city="Madrid",
            country="Spain",
        ),
    )
    ```

    </CodeGroup>

## Properties {{ tag: 'property', label: 'Computed & Resolved' }}

Because several metadata fields accept `None` when omitted, `Court` exposes `effective_*` properties that always return concrete resolved values matching the rules of `BallPhysicsEngine` and `PadelVisualizer`:

<Properties>
  <Property name="length" type="float">
    Shorthand for `self.dimensions.length` in meters (`20.0` standard).
  </Property>
  <Property name="width" type="float">
    Shorthand for `self.dimensions.width` in meters (`10.0` standard).
  </Property>
  <Property name="effective_turf_color" type="str">
    Resolved surface color string (`"blue"` if `turf_color` is `None`).
  </Property>
  <Property name="effective_enclosure_type" type="EnclosureType">
    Resolved solid wall material (`EnclosureType.GLASS` if unset).
  </Property>
  <Property name="effective_enclosure_variant" type="EnclosureVariant">
    Resolved perimeter height variant: returns `enclosure_variant` if set, `V2` when `dimensions.side_wall_height >= 4.0`, otherwise `V1`.
  </Property>
  <Property name="effective_side_wall_profile" type="SideWallProfile">
    Resolved solid end-zone silhouette: returns `side_wall_profile` if set, `STEPPED` for `EnclosureType.WALL`, or `UNIFORM` for `EnclosureType.GLASS`.
  </Property>
  <Property name="effective_access_left" type="SideAccess">
    Resolved left doorway geometry (defaults to `SideAccess.fip_single_access()` when `access_left` is `None`).
  </Property>
  <Property name="effective_access_right" type="SideAccess">
    Resolved right doorway geometry (defaults to `SideAccess.fip_single_access()` when `access_right` is `None`).
  </Property>
</Properties>

## `landmarks_2d()` {{ tag: 'method', label: 'court.landmarks_2d()' }}

<Row>
  <Col>

    Returns a dictionary mapping the **13 floor landmarks** (`Z = 0.0`) to `(X, Y)` coordinate pairs in meters.

    ### Arguments
    <Properties>
      <Property name="coordinate_system" type="CoordinateSystem">
        Spatial reference frame for returned points (`CoordinateSystem.CENTERED` or `CoordinateSystem.CORNER_BASED`). Defaults to `CoordinateSystem.CENTERED`.
      </Property>
    </Properties>

    ### Returns
    <Properties>
      <Property name="landmarks" type="dict[str, tuple[float, float]]">
        Dictionary mapping each floor [`CourtLandmark`](/court-landmark) string value to `(X, Y)` in meters.
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="2D Floor Landmarks" tag="method" label="landmarks_2d">

    ```python
    from padelkit import CoordinateSystem, Court

    court = Court.fip_standard()
    pts_centered = court.landmarks_2d()
    pts_corner = court.landmarks_2d(CoordinateSystem.CORNER_BASED)

    print("Center (centered):", pts_centered["center"])
    print("Center (corner):", pts_corner["center"])
    # Center (centered): (0.0, 0.0)
    # Center (corner): (5.0, 10.0)
    ```

    </CodeGroup>

  </Col>
</Row>

## `side_wall_heights_at()` {{ tag: 'method', label: 'court.side_wall_heights_at()' }}

<Row>
  <Col>

    Evaluates `(solid_height_m, total_height_m)` on the sideline at a given longitudinal distance inward from the nearest back wall (`0.0 m` at the back glass corner up to `length / 2 = 10.0 m` at the net).

    ### Arguments
    <Properties>
      <Property name="dist_from_back" type="float">
        Distance inward from the nearest back wall in meters (clamped at `>= 0.0`).
      </Property>
    </Properties>

    ### Returns
    <Properties>
      <Property name="heights" type="tuple[float, float]">
        `(solid_height_m, total_height_m)` in meters (`solid_height_m` is `0.0` in pure wire-mesh zones beyond `4.0 m`).
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Query Side Heights" tag="method" label="side_wall_heights_at">

    ```python
    from padelkit import Court, EnclosureType

    wall_court = Court(enclosure_type=EnclosureType.WALL)
    print("At 1.5 m:", wall_court.side_wall_heights_at(1.5))  # (3.0, 4.0)
    print("At 3.0 m:", wall_court.side_wall_heights_at(3.0))  # (2.0, 3.0)
    print("At 6.0 m:", wall_court.side_wall_heights_at(6.0))  # (0.0, 3.0)
    ```

## `side_enclosure_panels()` {{ tag: 'method', label: 'court.side_enclosure_panels()' }}

      </Property>
    </Properties>

    ### Returns
    <Properties>
      <Property name="panels" type="list[SideEnclosurePanel]">
        All non-empty rectangular solid and mesh panels along that sideline.
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Full Sideline Panels" tag="method" label="side_enclosure_panels">

## `is_doorway_opening_at()` {{ tag: 'method', label: 'court.is_doorway_opening_at()' }}

<Row>
  <Col>

    Exact geometric collision check used by [`BallPhysicsEngine`](/ball-physics-engine): returns `True` only when the sideline door is not closed (`door_state_for(side) != DoorState.CLOSED`) and the ball circle fits completely inside one of the doorway `[Y0, Y1] × [0, access.height]` openings without clipping frames or the overhead wire lintel.

    ### Arguments
    <Properties>
      <Property name="side" type='Literal["left", "right"]'>
        Sideline to check (`"left"` or `"right"`).
      </Property>
      <Property name="y_centered" type="float">
        Longitudinal Y coordinate in CENTERED meters (`Y = 0.0` is the net).
      </Property>
      <Property name="z" type="float">
        Vertical ball elevation above the floor in meters.
      </Property>
      <Property name="radius" type="float">
        Optional ball radius clearance margin in meters (`0.0` default for point test).
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Doorway Pass-Through" tag="method" label="is_doorway_opening_at">

    ```python
    from padelkit import Court

    court = Court.fip_standard()  # default 2.0m x 2.2m centered doorways
    print(court.is_doorway_opening_at("left", y_centered=0.0, z=1.5))  # True
    print(court.is_doorway_opening_at("left", y_centered=0.0, z=2.5))  # False (lintel)
    ```

    </CodeGroup>

  </Col>
</Row>

## FIP Regulatory Validation {{ tag: 'method', label: 'is_fip_compliant / is_out_of_court_play_allowed' }}

<Row>
  <Col>

    Four complementary methods verify official FIP compliance across dimensions, door counts/sizes, Rule 16 exterior clearance, indoor ceiling height, and turf palette:

    <Properties>
      <Property name="has_fip_compliant_access(out_of_court_play=False)" type="bool">
        Verifies both sidelines have compliant doorway dimensions and either `>= 1` access total (standard) or `2` doorways on both sides (`out_of_court_play=True`).
      </Property>
      <Property name="is_out_of_court_play_allowed()" type="bool">
        Returns `True` when both sidelines support dual doorways and any configured `SafetyZone` meets the `2.0 m × 8.0 m × 3.0 m` (`>= 2 cm` padding) Rule 16 clearance.
      </Property>
      <Property name="fip_compliance_issues(out_of_court_play=False)" type="list[str]">
        Returns a human-readable list of every FIP deviation (dimensions, ceiling `< 6.0 m`, doorways, safety zone, non-standard or outdoor-black turf). Empty list means fully compliant.
      </Property>
      <Property name="is_fip_compliant(out_of_court_play=False)" type="bool">
        Convenience boolean shorthand equivalent to `len(court.fip_compliance_issues(...)) == 0`.
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Audit FIP Rules" tag="method" label="Compliance Checks">

    ```python
    from padelkit import Court, CourtSetting, CourtSurfaceColor

    outdoor_black = Court(
        turf_color=CourtSurfaceColor.BLACK,
        setting=CourtSetting.OUTDOOR,
    )
    print(outdoor_black.is_fip_compliant())
    print(outdoor_black.fip_compliance_issues())
    # False
    # ['black turf is only FIP-approved on indoor courts.']
    ```

    </CodeGroup>

  </Col>
</Row>

## Serialization (`to_dict` / `from_dict`) {{ tag: 'method', label: 'dict I/O' }}

<Row>
  <Col>

    Losslessly serializes all geometry, optional attributes, doors, safety zones, ceiling height, and [`CourtLocation`](/court-location) metadata to JSON-friendly dictionaries (`court.to_dict()`) and reconstructs identical instances (`Court.from_dict(data)`).

  </Col>
  <Col sticky>

    <CodeGroup title="Dictionary Round-Trip" tag="method" label="to_dict / from_dict">

    ```python
    from padelkit import Court

    court = Court.fip_standard()
    payload = court.to_dict()
    restored = Court.from_dict(payload)
    assert restored == court
    ```

    </CodeGroup>

  </Col>
