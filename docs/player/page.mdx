# Player

`Player` is a dataclass representing an individual padel player, including optional receiving half preference (`"left"` / backhand vs `"right"` / drive) and nationality metadata. Import via `from padelkit import Player`. {{ className: 'lead' }}

Two `Player` objects are paired into a [`Team`](/team). When `side` is set, [`ServingEngine`](/serving-engine) uses it to determine automatically which opponent receives serves into the `"right"` (deuce) vs `"left"` (ad) service box.

---

## Parameters & Fields {{ tag: 'dataclass', label: 'Player' }}

<Row>
  <Col>

    <Properties>
      <Property name="name" type="str">
        Display name of the player (e.g. `"Arturo Coello"`). Must be unique across teammates and opposing pairs within a match.
      </Property>
      <Property name="side" type='Literal["left", "right"] | None'>
        Receiving side of the court occupied by this player (`"right"` / drive side vs `"left"` / revés side, viewed from near side facing net). Defaults to `None` (`player1` covers right, `player2` covers left).
      </Property>
      <Property name="nationality" type="str | None">
        Optional country name or ISO code (`"ES"`, `"AR"`, etc.). Defaults to `None`.
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Initialization" tag="dataclass" label="Player">

    ```python
    from padelkit import Player

    player = Player(name="Agustín Tapia", side="left", nationality="AR")
    print(player.name, "| side:", player.side)
    ```

    </CodeGroup>

  </Col>
</Row>

<Row>
