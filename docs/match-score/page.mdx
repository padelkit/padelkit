# MatchScore

`MatchScore` is a frozen dataclass representing an **immutable point-in-time scoreboard snapshot** returned by [`MatchScoreHistory.add_point()`](/match-score-history#add-point) and [`get_current_score()`](/match-score-history#get-current-score). Import via `from padelkit import MatchScore`. {{ className: 'lead' }}

In addition to points, games, completed sets, and [`ServingState`](/serving-state), `MatchScore` automatically computes FIP Rule 5 court end switches (`side_changes`, `team_a_side`, `is_side_change`).

---

## Parameters & Fields {{ tag: 'dataclass', label: 'MatchScore' }}

<Row>
  <Col>

    <Properties>
      <Property name="points_A" type="int | str">
        Current game score for Team A (`0`, `15`, `30`, `40`, `"AD"`, or integer tiebreak points).
      </Property>
      <Property name="points_B" type="int | str">
        Current game score for Team B (`0`, `15`, `30`, `40`, `"AD"`, or integer tiebreak points).
      </Property>
      <Property name="games_A" type="int">
        Games won by Team A in the active set.
      </Property>
      <Property name="games_B" type="int">
        Games won by Team B in the active set.
      </Property>
      <Property name="sets_A" type="int">
        Completed sets won by Team A.
      </Property>
      <Property name="sets_B" type="int">
        Completed sets won by Team B.
      </Property>
      <Property name="completed_sets" type="list[tuple[int, int]]">
        Chronological list of `(games_A, games_B)` tuples for every finished set (e.g. `[(6, 4), (3, 6)]`).
      </Property>
      <Property name="server" type="ServingState | None">
        Resolved active [`ServingState`](/serving-state) (serving team, player, receiver, and court box). Defaults to `None`.
      </Property>
      <Property name="teams" type="dict[TeamId, Team] | None">
        Optional team definitions attached for readable scoreboard labels in `str(score)`. Defaults to `None`.
      </Property>
      <Property name="in_tiebreak" type="bool">
        `True` when a regular 7-point set tiebreak (or match tiebreak) is in progress. Defaults to `False`.
      </Property>
      <Property name="in_super_tiebreak" type="bool">
        `True` when a 10-point match-deciding super-tiebreak is active. Defaults to `False`.
      </Property>
      <Property name="is_gold_point" type="bool">
        `True` when the score stands at `40-40` under `"gold_point"` (*Punto de Oro*). Defaults to `False`.
      </Property>
      <Property name="side_changes" type="int">
        Cumulative number of FIP Rule 5 court end switches triggered so far (`odd` games and every `6` tiebreak points). Defaults to `0`.
      </Property>
      <Property name="team_a_side" type='Literal["near", "far"]'>
        Which physical court end Team A currently occupies (`"near"` on even `side_changes`, `"far"` on odd). Defaults to `"near"`.
      </Property>
      <Property name="is_side_change" type="bool">
        `True` when the point immediately preceding this snapshot triggered players to switch ends. Defaults to `False`.
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Inspect Score Snapshot" tag="dataclass" label="MatchScore">

    ```python
    from padelkit import Match, TeamId

    match = Match()
    # Team A wins a love game (4 points -> triggers FIP Rule 5 side change after Game 1)
    for _ in range(4):
        score = match.history.add_point(TeamId.A)

    print("Games:", score.games_A, "-", score.games_B)
    print("Side change triggered?", score.is_side_change)  # True
    print("Team A side:", score.team_a_side)               # "far"
    ```

    </CodeGroup>

  </Col>

## String Formatting (`__str__`) {{ tag: 'method', label: 'str(score)' }}

<Row>
  <Col>

    `MatchScore` implements `__str__()` so calling `print(score)` displays a clean two-line broadcast scoreboard containing pair names (when `teams` are set), completed sets, active games, current points (`"AD"` for advantage), and an asterisk `*` next to the serving team.

  </Col>
  <Col sticky>

    <CodeGroup title="Formatted Scoreboard" tag="method" label="str(score)">

    ```python
    from padelkit import Match, TeamId

    match = Match()
    match.history.add_point(TeamId.A)
    print(match.history.get_current_score())
    ```

    </CodeGroup>

    ```text {{ title: 'Output' }}
    TEAM A (Player 1 / Player 2) | 0 | 15 *
    TEAM B (Player 3 / Player 4) | 0 |  0
    ```

  </Col>
</Row>
