# PlayerPose

`PlayerPose` is a frozen dataclass storing a player's court position, facing heading (`yaw_deg`), active stroke clip tag, normalized swing phase, and optional 17-joint Human3.6M (`H36M`) 3D skeletal pose at a single frame. Import via `from padelkit import PlayerPose`. {{ className: 'lead' }}

**Conventions:** Root `(x, y, z)` uses [`CoordinateSystem.CENTERED`](/court-enums#coordinate-system) meters; `yaw_deg` matches [`CameraExtrinsics`](/camera-extrinsics) (`0°` faces `+Y` toward the far wall, `180°` faces `-Y`, `+90°` faces `+X`). When `keypoints_3d` is provided, joints sit in the **player's local frame** (pelvis XY centered at `(0, 0)`, floor at `Z = 0.0`, facing `+Y`), following [`H36M_JOINT_NAMES`](/viz-constants#h36-m-joint-names).

## Parameters & Fields {{ tag: 'dataclass', label: 'PlayerPose' }}

<Row>
  <Col>

    <Properties>
      <Property name="player_id" type="str">
        Unique slot identifier (`"P1"`, `"P2"`, `"P3"`, or `"P4"`).
      </Property>
      <Property name="x" type="float">
        Lateral X coordinate of the player root on the court in meters (`[-5.0, 5.0]` inside).

      <Property name="y" type="float">
        Longitudinal Y coordinate of the player root in meters (`[-10.0, 10.0]` inside).
      </Property>
      <Property name="z" type="float">
        Vertical elevation offset of the player root above the court floor in meters. Defaults to `0.0`.
      </Property>
      <Property name="yaw_deg" type="float">
        Horizontal facing angle in degrees (`0.0` = `+Y`, `180.0` = `-Y`). Defaults to `0.0`.
      </Property>
      <Property name="animation" type="str">
        Canonical action/stroke tag matched by `PadelVisualizer` (`"idle"`, `"run"`, `"serve"`, `"shot_forehand"`, `"shot_backhand"`, `"shot_volley"`, `"shot_bandeja"`, `"shot_vibora"`, `"shot_lob"`, `"shot_smash"`). Defaults to `"idle"`.
      </Property>
      <Property name="team" type="str">
        Team assignment string (`"A"` or `"B"`). Defaults to `"A"`.
      </Property>
      <Property name="swing_phase" type="float">
        Normalized stroke progression phase in `[0.0, 1.0]` used to synchronize `.glb` and baked impact frames (`1.0` at ball impact). Defaults to `0.0`.
      </Property>
      <Property name="keypoints_3d" type="tuple[tuple[float, float, float], ...] | None">

      </Property>

<Properties>

## `from_world_keypoints_3d()` {{ tag: 'classmethod', label: 'PlayerPose.from_world_keypoints_3d()' }}

<Row>
  <Col>

    Constructs a `PlayerPose` directly from 3D motion-capture or lifted camera joints `(17, 3)` in world court meters—automatically extracting root `(x, y, z)` from Pelvis (`0`) and minimum ankle height, estimating facing `yaw_deg` from the hip vector (`RightHip -> LeftHip`) if omitted, and inverse-rotating joints into canonical local space.

    ### Arguments
    <Properties>
      <Property name="player_id" type="str">
        Player slot ID (`"P1"`–`"P4"`).
      </Property>
      <Property name="world_keypoints_3d" type="Sequence[Sequence[float]] | np.ndarray">
        `17 × 3` world joint coordinates ordered per [`H36M_JOINT_NAMES`](/viz-constants#h36-m-joint-names).
      </Property>
      <Property name="yaw_deg" type="float | None">
        Optional explicit facing angle in degrees (inferred from pelvis orientation when `None`).
      </Property>
      <Property name="animation" type="str">
        Action/stroke label. Defaults to `"idle"`.
      </Property>
      <Property name="team" type="str">
        Team string (`"A"` or `"B"`). Defaults to `"A"`.
      </Property>
      <Property name="swing_phase" type="float">
        Normalized stroke phase `[0.0, 1.0]`. Defaults to `0.0`.
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Lift World Joints to PlayerPose" tag="classmethod" label="from_world_keypoints_3d">

    ```python
    import numpy as np
    from padelkit import PlayerPose

    world_kps = np.zeros((17, 3))
    world_kps[:, 2] = 0.9
    world_kps[3, 2] = world_kps[6, 2] = 0.08  # ankles near floor
    world_kps[1, :2] = [0.15, 0.0]            # RightHip (+X)
    world_kps[4, :2] = [-0.15, 0.0]           # LeftHip (-X)

    pose = PlayerPose.from_world_keypoints_3d("P1", world_kps)
    print("Yaw:", pose.yaw_deg, "| Joints:", len(pose.world_keypoints_3d))
    ```

    </CodeGroup>

  </Col>
</Row>

## `to_dict()` {{ tag: 'method', label: 'pose.to_dict()' }}

<Row>
  <Col>

    Serializes player root fields (`player_id`, `x`, `y`, `z`, `yaw_deg`, `animation`, `team`, `swing_phase`) and includes `kp3d` (17 rounded `[x, y, z]` triples) whenever `keypoints_3d` is populated.

  </Col>

    print(pose.to_dict())
