# MatchConfiguration

`MatchConfiguration` is a self-validating dataclass encapsulating all tournament and format rules for a padel match. Import via `from padelkit import MatchConfiguration`. {{ className: 'lead' }}

Unlike plain dataclasses, `MatchConfiguration` hooks both `__post_init__` and `__setattr__` to invoke [`validate()`](#validate) on every change—making it impossible to assign an even `best_of_sets` or an invalid `advantage_method`.

---

## Parameters & Fields {{ tag: 'dataclass', label: 'MatchConfiguration' }}

<Row>
  <Col>

    <Properties>
      <Property name="best_of_sets" type="int">
        Maximum number of sets in the match. Must be a positive odd integer (`1`, `3`, `5`, ...). Defaults to `3`.
      </Property>
      <Property name="advantage_method" type='Literal["advantage", "gold_point"]'>
        Deuce resolution at `40-40`: traditional `"advantage"` vs FIP *Punto de Oro* (`"gold_point"`). Defaults to `"advantage"`.
      </Property>
      <Property name="set_format" type='Literal["standard", "mini"]'>
        Games per set: `"standard"` (first to 6, tiebreak at 6-6) or `"mini"` (first to 4, tiebreak at 4-4). Defaults to `"standard"`.
      </Property>
      <Property name="deciding_set_format" type='Literal["regular", "tiebreak", "super_tiebreak"]'>
        Rule when sets are tied heading into the final set: full `"regular"` set, 7-point `"tiebreak"`, or 10-point `"super_tiebreak"`. Defaults to `"regular"`.
      </Property>
      <Property name="starting_server_team" type="TeamId">
        Team serving Game 1 of Set 1 (`TeamId.A` or `TeamId.B`). Defaults to `TeamId.A`.
      </Property>
      <Property name="set_starting_servers" type="dict[int, dict[TeamId, Player]]">
        Optional overrides mapping 1-based set numbers (`1`, `2`, ...) to `{TeamId: Player}` designating who serves first for each pair in that set. Defaults to empty dict `{}`.
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Initialization" tag="dataclass" label="MatchConfiguration">

    ```python
    from padelkit import MatchConfiguration, TeamId

    cfg = MatchConfiguration(
        best_of_sets=3,
        advantage_method="gold_point",
        set_format="standard",
        deciding_set_format="super_tiebreak",
        starting_server_team=TeamId.B,
    )
    ```

    </CodeGroup>

  </Col>
</Row>

## `validate()` {{ tag: 'method', label: 'config.validate()' }}

<Row>
  <Col>

    Validates every rule constraint and raises `ValueError` immediately if any value is out of bounds (`best_of_sets` even or `<= 0`, unknown format string, non-positive set index, or non-`Player` value in `set_starting_servers`). Called automatically on construction and attribute mutation.

  </Col>
  <Col sticky>

    <CodeGroup title="Automatic Validation" tag="method" label="validate">

    ```python
    from padelkit import MatchConfiguration

    cfg = MatchConfiguration(best_of_sets=3)
    try:
        cfg.best_of_sets = 2  # triggers validate()
    except ValueError as exc:
        print("Rejected invalid rule:", exc)
    ```

    </CodeGroup>

  </Col>
</Row>

## Serialization (`to_dict` / `from_dict`) {{ tag: 'method', label: 'dict I/O' }}

<Row>
  <Col>

    Exports rules and custom `set_starting_servers` mappings (`config.to_dict()`) and reconstructs an identical validated configuration (`MatchConfiguration.from_dict(data)`).

  </Col>
  <Col sticky>

    <CodeGroup title="Dictionary Round-Trip" tag="method" label="to_dict / from_dict">

    ```python
    from padelkit import MatchConfiguration

    cfg = MatchConfiguration(advantage_method="gold_point", set_format="mini")
    assert MatchConfiguration.from_dict(cfg.to_dict()) == cfg
    ```

    </CodeGroup>

  </Col>
</Row>
