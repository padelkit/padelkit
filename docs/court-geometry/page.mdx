# Court Geometry

The court module defines the dimensions, landmarks, and coordinate system of an official padel court. On this page, we'll dive into the different classes and methods you can use to interact with court geometry programmatically. {{ className: 'lead' }}

## The CourtDimensions model

The `CourtDimensions` dataclass houses the official measurements of the court. All units are expressed in meters.

## Coordinate Systems

PadelKit supports two spatial reference frames via `CoordinateSystem`:

- **`CoordinateSystem.CENTERED` (default):** Origin `(0.0, 0.0, 0.0)` lies at the center of the net on the court floor, with `X` in `[-5.0, 5.0]` and `Y` in `[-10.0, 10.0]`.
- **`CoordinateSystem.CORNER_BASED`:** Origin `(0.0, 0.0, 0.0)` lies at `floor_near_left`, shifting horizontal coordinates by `(+5.0m, +10.0m)` so `X` is in `[0.0, 10.0]` and `Y` is in `[0.0, 20.0]`.

## Enclosure Types & Regulatory Variants

According to the official FIP *Rules of Padel*, every court enclosure combines solid rebound panels (tempered glass or masonry wall) with electro-welded or woven metallic mesh fencing:

- **Back walls (`10.0 m` width × `4.0 m` total height):** Always composed of **`3.0 m`** of solid wall (`EnclosureType.GLASS` or `EnclosureType.WALL`) topped by **`1.0 m`** of metallic mesh.
- **Side enclosures (`20.0 m` length):** Defined along three orthogonal axes in [`Court`](/court):
  1. **Material (`EnclosureType`):** `GLASS` (tempered safety glass EN 12150-1, low friction) vs. `WALL` (brick/concrete wall, higher spin grip). Per FIP rules, walls may be built from any smooth, uniform transparent or opaque material (`GLASS` or `WALL`)—both `STEPPED` glass and `STEPPED` masonry walls are valid, whereas floor surfaces (`SurfaceType`: turf, porous concrete, acrylic, wood) are independent of enclosure choice.
  2. **Upper mesh height (`EnclosureVariant`):** `V1` drops the central `16.0 m` metallic mesh to **`3.0 m`** (rising to `4.0 m` only in the `2.0 m` corners), whereas `V2` keeps a uniform **`4.0 m`** mesh height across the full `20.0 m`.
  3. **Solid end-zone profile (`SideWallProfile`):** `STEPPED` places two stepped solid panels (`3.0 m × 2.0 m` + `2.0 m × 2.0 m`) at each end, while `UNIFORM` (*Variant 1/2 Crystal*, "sin escalón") uses a continuous **`3.0 m × 4.0 m`** panel with no step down. When `side_wall_profile` is left as `None`, `WALL` courts default to `STEPPED` and `GLASS` courts default to `UNIFORM` (or pass `SideWallProfile.STEPPED` explicitly for stepped glass courts).

|---|---|---|---|---|---|

| **Variant 1 Crystal** | `GLASS` | `V1` | `UNIFORM` | `3m×4m` flat | `3.0 m` |

<Row>
  <Col>

    <Properties>
      <Property name="enclosure_type" type="EnclosureType" optional default="None">
        Solid rebound wall material (`GLASS` or `WALL`). Determines whether stepped vs flat profile defaults to `UNIFORM` (`GLASS`) or `STEPPED` (`WALL`) when `side_wall_profile` is omitted.
      </Property>
      <Property name="enclosure_variant" type="EnclosureVariant" optional default="None">
        Upper metallic mesh profile along the central `16.0 m` (`V1` at `3.0 m` vs `V2` at `4.0 m`). Defaults from `dimensions.side_wall_height`.
      </Property>
      <Property name="side_wall_profile" type="SideWallProfile" optional default="None">
        Solid end-zone silhouette over `0..4 m` from each back corner: `STEPPED` (`3m×2m + 2m×2m`) or `UNIFORM` (continuous `3m×4m` without step).
      </Property>
    </Properties>

    Access openings sit symmetrically on the net axis (`1` opening of `1.05–2.00 m × 2.00–2.20 m`, or `2` openings of `0.72–1.00 m × 2.00–2.20 m` per side), topped by metallic wire mesh lintels up to the perimeter roof (`3.0 m` in `V1`, `4.0 m` in `V2`). Both [`BallPhysicsEngine`](/ball-physics-engine) and [`PadelVisualizer`](/padel-visualizer) query `court.side_wall_heights_at()`, `court.is_doorway_opening_at()`, and `court.side_enclosure_panels()` directly so collisions and 3D meshes always match.

  </Col>
  <Col sticky>

    <CodeGroup title="Configure Enclosure Variants" tag="enum" label="SideWallProfile">

    ```python
    from padelkit import (
        Court,
        CourtDimensions,
        EnclosureType,
        EnclosureVariant,
        SideWallProfile,
    )

    # 1. FIP Variant 1 — Stepped masonry wall (default STEPPED)
    wall_v1 = Court(
        enclosure_type=EnclosureType.WALL,
        enclosure_variant=EnclosureVariant.V1,
    )

    # 2. FIP Variant 1 — Stepped tempered glass (explicit STEPPED)
    glass_stepped = Court(
        enclosure_type=EnclosureType.GLASS,
        enclosure_variant=EnclosureVariant.V1,
        side_wall_profile=SideWallProfile.STEPPED,
    )

    # 3. FIP Variant 2 Crystal — Non-stepped 3m x 4m glass + 4m mesh
    crystal_v2 = Court(
        dimensions=CourtDimensions.fip_variant_2(),
        enclosure_type=EnclosureType.GLASS,
        enclosure_variant=EnclosureVariant.V2,
        side_wall_profile=SideWallProfile.UNIFORM,
    )

    # Query exact (solid_h, total_h) 3.0m inward from back wall
    solid_h, total_h = crystal_v2.side_wall_heights_at(3.0)
    ```

    </CodeGroup>

    ```json {{ title: 'Output (crystal_v2 at 3.0m)' }}
    (3.0, 4.0)
    ```

  </Col>
</Row>

## Lateral Access Openings (Doors) {{ tag: 'dataclass', label: 'SideAccess' }}

<Schematic
  name="court-side-access"
  alt="Lateral Access Openings (1 vs 2 vs 0 Doors per Side)"
  caption="Central sideline elevation (Y ∈ [-4, +4] m) and plan view showing 1-door default, 2-door Rule 16 out-of-court play + SafetyZone, and 0-door single-side entry club courts."
/>

| Access Configuration | Preset / `count` | Official Width × Height (each) | Regulatory Notes |
| :--- | :--- | :--- | :--- |
| **Single Access** (default) | `SideAccess.fip_single_access()` (`1`) | `1.05–2.00 m × 2.00–2.20 m` | Default `2.00 m × 2.20 m` (FIP max); overhead mesh lintel from `height` to `3.0 / 4.0 m` |
| **Dual Access** (out-of-court) | `SideAccess.fip_dual_access()` (`2`) | `0.72–1.00 m × 2.00–2.20 m` | Dual openings separated by a central structural post; required on **both** sides for out-of-court play |
| **No Access** (closed side) | `SideAccess.no_access()` (`0`) | Continuous `12 m` wire mesh | Common on recreational courts with access on one side only |

<Row>
  <Col>

    By default, `Court` exposes a single `2.00 m × 2.20 m` doorway centered at the net (`Y ∈ [-1.0, +1.0]`) on both sidelines (`access_left` and `access_right`), matching the maximum official FIP single-access dimensions. Above the doorway lintel (`Z > access.height`), metallic mesh continues up to the enclosure top (`3.0 m` or `4.0 m`), rebounding high balls while letting open-doorway shots pass out of court.

    Non-official club layouts — such as courts with access on only one side (`access_right=SideAccess.no_access()`), custom door dimensions, or `DoorState.CLOSED` gates — are configured per side without errors and checked via `court.has_fip_compliant_access(out_of_court_play=...)`.

    <Properties>
      <Property name="SideAccess.count" type="0 | 1 | 2" default="1">
        Number of doorway openings centered symmetrically at the net on that sideline.
      </Property>
      <Property name="SideAccess.width" type="float" default="2.0">
        Clear width of each doorway opening in meters.
      </Property>
      <Property name="SideAccess.height" type="float" default="2.2">
        Clear vertical height in meters below the overhead wire mesh lintel.
      </Property>
      <Property name="SideAccess.center_pillar_width" type="float" default="0.16">
        Width in meters of the structural post separating dual openings when `count == 2`.
      </Property>
      <Property name="SafetyZone(width=2.0, half_length=4.0, height=3.0)" type="dataclass">
        Exterior obstacle-free clearance zone (`safety_zone_left` / `safety_zone_right`) required for official Rule 16 out-of-court play (`>= 2.0 m` wide × `8.0 m` total length centered on the net × `>= 3.0 m` vertical clearance + `>= 2 cm` post/frame padding).
      </Property>
      <Property name="ceiling_height" type="float | None">
        Optional physical roof height in meters (`>= 6.0 m` FIP minimum, `8.0 m` suggested for new indoor construction). Triggers `SurfaceType.CEILING` collisions when set.
      </Property>
      <Property name="court.is_fip_compliant(out_of_court_play=False)" type="bool">
        Validates official FIP compliance across court dimensions, lateral access, `SafetyZone`, `ceiling_height`, and surface color (black turf indoor-only). Inspect `court.fip_compliance_issues()` for human-readable violations.
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Side Access, SafetyZone & Compliance" tag="dataclass" label="SideAccess / SafetyZone">

    ```python
    from padelkit import (
        Court,
        CourtSetting,
        CourtSurfaceColor,
        DoorState,
        SafetyZone,
        SideAccess,
    )

    # Official out-of-court layout: dual doorways + 2x8m SafetyZone on both sides
    pro_court = Court(
        turf_color=CourtSurfaceColor.BLUE,
        access_left=SideAccess.fip_dual_access(),
        access_right=SideAccess.fip_dual_access(),
        safety_zone_left=SafetyZone.fip_standard(),
        safety_zone_right=SafetyZone.fip_standard(),
    )
    pro_court.is_out_of_court_play_allowed()            # True
    pro_court.is_fip_compliant(out_of_court_play=True)  # True

    # Recreational single-side entry club court
    club_court = Court(
        access_left=SideAccess.fip_single_access(width=1.6, height=2.1),
        access_right=SideAccess.no_access(),
        door_left=DoorState.OPEN,
        setting=CourtSetting.INDOOR,
        ceiling_height=7.0,
        turf_color=CourtSurfaceColor.BLACK,
    )

    # Query physics pass-through at the net (y=0.0, z=1.4m)
    club_court.is_doorway_opening_at("left", y_centered=0.0, z=1.4)   # True
    club_court.is_doorway_opening_at("left", y_centered=0.0, z=2.5)   # False (lintel)
    club_court.is_doorway_opening_at("right", y_centered=0.0, z=1.4)  # False (mesh)
    ```

    </CodeGroup>

  </Col>
</Row>

## The Court model

The `Court` class is the main geometry model. By default, it uses `CoordinateSystem.CENTERED` where `(0.0, 0.0)` is at the midpoint of the net. The **X** axis represents the width, and the **Y** axis represents the length.

### Properties

<Properties>
  <Property name="dimensions" type="CourtDimensions">
    An instance of the `CourtDimensions` class containing the physical measurements.
  </Property>
</Properties>

## Standard Initialization {{ tag: 'classmethod', label: 'Court.fip_standard()' }}

<Row>
  <Col>

    This class method allows you to easily instantiate a `Court` using the standard measurements established by the International Padel Federation (FIP).

    By default, an FIP court is 20.0m in length and 10.0m in width.

  </Col>
  <Col sticky>

    <CodeGroup title="Instantiation" tag="classmethod" label="fip_standard">

    ```python
    from padelkit import Court

    court = Court.fip_standard()
    ```

    </CodeGroup>

    ```json {{ title: 'Output structure' }}
    Court(
      dimensions=CourtDimensions(length=20.0, width=10.0)
    )
    ```

  </Col>
</Row>

## Get a landmark coordinate {{ tag: 'method', label: 'court.point()' }}

<Row>
  <Col>

    This method allows you to retrieve the exact `(x, y)` coordinates of a specific standard landmark on the court.

    ### Required arguments

    <Properties>
      <Property name="name" type="CourtLandmark | str">
        The name of the landmark. This can be an instance of the `CourtLandmark` Enum (e.g., `CourtLandmark.CENTER`) or its string equivalent (e.g., `"center"`).
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Usage" tag="method" label="point">

    ```python
    from padelkit import Court

    court = Court.fip_standard()
    net_center = court.point("center")
    ```

    </CodeGroup>

    ```json {{ title: 'Output' }}
    (0.0, 0.0)
    ```

  </Col>
</Row>

## List all landmarks {{ tag: 'method', label: 'court.landmarks_2d()' }}

<Row>
  <Col>

    This method returns a dictionary containing all the standardized 2D positions of the court landmarks. It's useful if you need to draw the court or access multiple points at once.

  </Col>
  <Col sticky>

    <CodeGroup title="Usage" tag="method" label="landmarks_2d">

    ```python
    from padelkit import Court

    court = Court.fip_standard()
    all_points = court.landmarks_2d()
    ```

      "floor_near_right": [5.0, -10.0],
