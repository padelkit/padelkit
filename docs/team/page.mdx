# Team

`Team` is a dataclass grouping two distinct [`Player`](/player) instances under a pair identifier (`TeamId.A` or `TeamId.B`), tactical serving formation, and optional pair name. Import via `from padelkit import Team`. {{ className: 'lead' }}

`__post_init__` raises `ValueError` if `player1` and `player2` are equal or share the exact same `name`.

---

## Parameters & Fields {{ tag: 'dataclass', label: 'Team' }}

<Row>
  <Col>

    <Properties>
      <Property name="id" type="TeamId">
        Team slot identifier (`TeamId.A` or `TeamId.B`). See [`TeamId`](/scoring-enums#team-id).
      </Property>
      <Property name="player1" type="Player">
        First player of the pair (serves first in a set unless overridden by `set_starting_servers`).
      </Property>
      <Property name="player2" type="Player">
        Second player of the pair (must have a unique `name` distinct from `player1`).
      </Property>
      <Property name="serve_formation" type='Literal["standard", "australian"]'>
        Tactical serving formation (`"standard"` side-switching vs `"australian"` fixed court halves). Defaults to `"standard"`.
      </Property>
      <Property name="name" type="str | None">
        Optional custom pair label (e.g. `"Golden Duo"`). Defaults to `None` (`display_name` falls back to `"player1 / player2"`).
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Initialization" tag="dataclass" label="Team">

    ```python
    from padelkit import Player, Team, TeamId

    team_a = Team(
        id=TeamId.A,
        player1=Player("A. Coello", side="right", nationality="ES"),
        player2=Player("A. Tapia", side="left", nationality="AR"),
        serve_formation="australian",
    )
    print(team_a.display_name)
    # A. Coello / A. Tapia
    ```

    </CodeGroup>

  </Col>
</Row>

## Properties {{ tag: 'property', label: 'Display Name' }}

<Properties>
  <Property name="display_name" type="str">
    Returns `name` if specified, otherwise automatically formats `f"{player1.name} / {player2.name}"`.
  </Property>
</Properties>

## Serialization (`to_dict` / `from_dict`) {{ tag: 'method', label: 'dict I/O' }}

<Row>
  <Col>

    Exports `id`, `player1`, `player2`, `serve_formation`, and `name` into a JSON-friendly dictionary (`team.to_dict()`) and restores an identical `Team` instance (`Team.from_dict(data)`).

  </Col>
  <Col sticky>

    <CodeGroup title="Dictionary Round-Trip" tag="method" label="to_dict / from_dict">

    ```python
    from padelkit import Player, Team, TeamId

    team = Team(TeamId.B, Player("A. Galan"), Player("F. Chingotto"))
    assert Team.from_dict(team.to_dict()) == team
    ```

    </CodeGroup>

  </Col>
