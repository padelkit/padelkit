# PadelVisualizer

`PadelVisualizer` builds and serves the interactive **Three.js 3D court studio** for PadelKit. It renders regulatory courts (glass/masonry walls, wire mesh, open/closed doorways, safety zones, indoor ceilings), spinning padel balls, trajectory ribbons, Mixamo `.glb` animated players, or 17-joint baked H36M skeletons, alongside computer vision render passes (`RGB`, `Segmentation`, `Depth`, and `17 Court Landmarks`). Import via `from padelkit import PadelVisualizer`. {{ className: 'lead' }}

<Note>
  `PadelVisualizer` embeds the Three.js runtime directly inside generated HTML by default (`offline=True`, added on the `0.1.1` development branch) so standalone exports work cleanly over `file://` URLs with zero internet connection. Pass `offline=False` to load Three.js via CDN instead.
</Note>

## Constructor {{ tag: 'constructor', label: 'PadelVisualizer' }}

<Row>
  <Col>

    All arguments are optional. Calling `PadelVisualizer()` with zero arguments launches a physics-simulated [`MatchTimeline.demo_rally()`](/match-timeline#demo-rally) with 5 standard venue cameras.

    <Properties>
      <Property name="court" type="Court | None">
        [`Court`](/court) geometry to render. Defaults to `timeline.court` or `Court.fip_standard()`.
      </Property>
      <Property name="cameras" type="list[Camera] | None">
        List of [`Camera`](/camera) presets or calibrated video views selectable in the studio HUD. Defaults to 5 views (`broadcast_near`, `broadcast_far`, `overhead_zenith`, `corner_near_left`, `side_net_right`).
      </Property>
      <Property name="timeline" type="MatchTimeline | None">
        [`MatchTimeline`](/match-timeline) recording or live buffer to display. Defaults to `MatchTimeline.demo_rally(...)`.
      </Property>
      <Property name="animation_library_dir" type="str | Path | None">
        Optional directory containing a `manifest.json` and Mixamo `.glb` clips generated by `padelkit-animator`. See [Stroke Library](/stroke-library). Defaults to `None`.
      </Property>
      <Property name="offline" type="bool">
        When `True` (default), embeds the Three.js library directly into output HTML for standalone offline use; when `False`, uses a CDN import map.
      </Property>
      <Property name="ball_properties" type="BallProperties | None">
        Optional visual [`BallProperties`](/ball-properties) (radius and turf contrast color). Defaults to `timeline.ball_properties`.
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Initialization" tag="constructor" label="PadelVisualizer">

    ```python
    from padelkit import Court, CourtSurfaceColor, PadelVisualizer

    viz = PadelVisualizer(
        court=Court(turf_color=CourtSurfaceColor.BLUE),
        offline=True,
    )
    viz.export_html("court_studio.html")
    ```

    </CodeGroup>

  </Col>
</Row>

## `from_parquet()` {{ tag: 'classmethod', label: 'PadelVisualizer.from_parquet()' }}

<Row>
  <Col>

    Factory constructor reading a Universal Match Format `.parquet` file via [`MatchTimeline.from_parquet()`](/match-timeline#to-parquet-and-from-parquet), automatically reconstructing embedded court geometry, ball properties, and 17-joint 3D skeletal frames.

    ### Arguments
    <Properties>
      <Property name="parquet_path" type="str | Path">
        Path to `.parquet` match file.
      </Property>
      <Property name="court" type="Court | None">
        Optional `Court` override (defaults to the `Court` stored in `padelkit_metadata`).
      </Property>
      <Property name="cameras" type="list[Camera] | None">
        Optional camera list.
      </Property>
      <Property name="animation_library_dir" type="str | Path | None">
        Optional directory of Mixamo `.glb` clips.
      </Property>
      <Property name="offline" type="bool">
        Embed Three.js bundle locally. Defaults to `True`.
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Load Parquet Match" tag="classmethod" label="from_parquet">

    ```python
    from padelkit import MatchTimeline, PadelVisualizer

    MatchTimeline.demo_rally(bake_skeleton=True).to_parquet("match.parquet")
    viz = PadelVisualizer.from_parquet("match.parquet")
    viz.export_html("replay.html")
    ```

    </CodeGroup>

  </Col>
</Row>

## `add_camera()`, `load_*()` & `build_config()` {{ tag: 'method', label: 'Scene Builders' }}

<Row>
  <Col>

    Fluent mutator methods returning `self` for method chaining:
    - **`add_camera(camera)`**: Appends a [`Camera`](/camera) viewpoint to `self.cameras`.
    - **`load_csv(csv_path)`**: Replaces `self.timeline` from a CSV file using `self.court`.
    - **`load_parquet(parquet_path)`**: Replaces `self.timeline` and `self.court` from a `.parquet` file.
    - **`load_animation_library(animation_library_dir)`**: Attaches a `padelkit-animator` directory.
    - **`build_config(live_stream_url=None)`**: Returns the complete JSON-serializable scene dictionary consumed by the Three.js frontend.

  </Col>
  <Col sticky>

    <CodeGroup title="Register Calibrated Camera" tag="method" label="add_camera">

    ```python
    from padelkit import Camera, PadelVisualizer

    viz = PadelVisualizer().add_camera(
        Camera.from_preset("corner_far_right")
    )
    scene_cfg = viz.build_config()
    print("Cameras loaded:", len(scene_cfg["cameras"]))
    ```

    </CodeGroup>

  </Col>
</Row>

## `export_html()`, `to_html()` & `_repr_html_()` {{ tag: 'method', label: 'HTML & Notebooks' }}

<Row>
  <Col>

    Render the studio outside Python without running a persistent web server:
    - **`export_html(path, offline=None)`**: Creates parent folders if necessary, writes the complete Three.js viewer HTML to `path`, and returns the resolved `Path`.
    - **`to_html(live_stream_url=None, offline=None)`**: Returns the raw HTML document string.
    - **`_repr_html_()`**: Automatically renders an embedded `<iframe>` (width 100%, height 640px) whenever a `PadelVisualizer` instance is evaluated in Jupyter or Google Colab.

    ### Arguments
    <Properties>
      <Property name="path" type="str | Path">
        Output `.html` destination path for `export_html()`.
      </Property>
      <Property name="offline" type="bool | None">
        Override `self.offline` for this export (`True` embeds Three.js inline; `False` loads from jsDelivr CDN; `None` uses `self.offline`).
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Export Offline HTML" tag="method" label="export_html">

    ```python
    from padelkit import PadelVisualizer

    viz = PadelVisualizer()
    out_file = viz.export_html("output/rally_viewer.html", offline=True)
    print("Wrote:", out_file)
    ```

    </CodeGroup>

  </Col>
</Row>

## `serve()` {{ tag: 'method', label: 'viz.serve()' }}

<Row>
  <Col>

    Starts a local `ThreadingHTTPServer` serving the interactive 3D viewer (`/`), optional `.glb` assets (`/animations/...`), and a Server-Sent Events stream (`/events`).

    ### Arguments
    <Properties>
      <Property name="host" type="str">
        Bind address. Defaults to `"127.0.0.1"`.
      </Property>
      <Property name="port" type="int">
        TCP listening port. Defaults to `8765`.
      </Property>
      <Property name="open_browser" type="bool">
        Automatically opens the URL in the default web browser. Defaults to `True`.
      </Property>
      <Property name="background" type="bool">
        If `True`, runs the server on a daemon thread and returns immediately so Python can call `push_frame()`; if `False`, blocks until `KeyboardInterrupt`. Defaults to `False`.
      </Property>
      <Property name="offline" type="bool | None">
        Override Three.js embedding mode (`None` falls back to `self.offline`).
      </Property>
    </Properties>

    ### Returns
    `ThreadingHTTPServer` — Active HTTP server handle.

  </Col>
  <Col sticky>

    <CodeGroup title="Launch Background Server" tag="method" label="serve">

    ```python
    from padelkit import PadelVisualizer

    viz = PadelVisualizer()
    server = viz.serve(port=8765, open_browser=False, background=True)
    # ... stream frames with viz.push_frame(...) ...
    viz.stop_server()
    ```

    </CodeGroup>

  </Col>
</Row>

## `push_frame()` & `stop_server()` {{ tag: 'method', label: 'Live Streaming' }}

<Row>
  <Col>

    - **`push_frame(frame)`**: Appends a [`FrameState`](/frame-state) snapshot to `self.timeline` and broadcasts its JSON payload over `/events` to all connected browser clients.
    - **`stop_server()`**: Gracefully shuts down and closes the background `ThreadingHTTPServer` started by `serve(background=True)`.

  </Col>
  <Col sticky>

    <CodeGroup title="Push Frame & Shutdown" tag="method" label="push_frame / stop_server">

    ```python
    from padelkit import FrameState, PadelVisualizer

    viz = PadelVisualizer()
    viz.serve(port=8770, open_browser=False, background=True)
    try:
        viz.push_frame(FrameState(timestamp=0.0, ball_position=(0.0, -3.0, 1.5)))
    finally:
        viz.stop_server()
    ```

    </CodeGroup>

  </Col>
</Row>
