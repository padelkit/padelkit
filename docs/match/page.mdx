# Match

`Match` is the top-level match aggregate uniting competing pairs (`teams`), format rules ([`MatchConfiguration`](/match-configuration)), the event-sourced point ledger ([`MatchScoreHistory`](/match-score-history)), venue metadata ([`Court`](/court)), match duration, and completion/winner detection. Import via `from padelkit import Match`. {{ className: 'lead' }}

If you only need pure score computation without teams, dates, or court links, you can also use [`MatchScoreHistory`](/match-score-history) directly. When `teams` is omitted, `Match()` creates default 2v2 teams (`Player 1` / `Player 2` vs. `Player 3` / `Player 4`).

## Constructor {{ tag: 'constructor', label: 'Match' }}

<Row>
  <Col>

    Pass either a complete `MatchConfiguration` object (`config`) or individual format keyword shortcuts (`best_of_sets`, `advantage_method`, `set_format`, `deciding_set_format`, `starting_server_team`, `set_starting_servers`).

    <Properties>
      <Property name="teams" type="dict[TeamId, Team] | None">
        Competing doubles pairs keyed by `TeamId.A` and `TeamId.B`. Defaults to auto-generated 4-player teams when `None`.
      </Property>
      <Property name="best_of_sets" type="int">
        Total maximum sets in the match (positive odd integer: `1`, `3`, `5`, ...). Defaults to `3`.
      </Property>
      <Property name="duration_minutes" type="int | None">
        Optional recorded match length in minutes. Defaults to `None`.
      </Property>
      <Property name="date" type="datetime | None">
        Optional match timestamp (`datetime`). Defaults to `None`.
      </Property>
      <Property name="court" type="Court | None">
        Optional [`Court`](/court) where the match took place. Defaults to `None`.
      </Property>
      <Property name="advantage_method" type="str">
        Deuce resolution rule (`"advantage"` or `"gold_point"`). Defaults to `"advantage"`.
      </Property>
      <Property name="set_format" type="str">
        Games needed per set (`"standard"` first to 6, or `"mini"` first to 4). Defaults to `"standard"`.
      </Property>
      <Property name="deciding_set_format" type="str">
        Final-set format (`"regular"`, `"tiebreak"` 7-pt, or `"super_tiebreak"` 10-pt). Defaults to `"regular"`.
      </Property>
      <Property name="starting_server_team" type="TeamId">
        Team serving Game 1 of Set 1 (`TeamId.A` default or `TeamId.B`).
      </Property>
      <Property name="set_starting_servers" type="dict[int, dict[TeamId, Player]] | None">
        Optional overrides specifying which player serves first for each team per 1-based set index. Defaults to `None`.
      </Property>
      <Property name="config" type="MatchConfiguration | None">
        Optional pre-built [`MatchConfiguration`](/match-configuration). Overrides individual format keyword arguments if provided.
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Initialization" tag="constructor" label="Match">

    ```python
    from datetime import datetime
    from padelkit import Court, Match, Player, Team, TeamId

    team_a = Team(TeamId.A, Player("A. Coello"), Player("A. Tapia"))
    team_b = Team(TeamId.B, Player("A. Galan"), Player("F. Chingotto"))

    match = Match(
        teams={TeamId.A: team_a, TeamId.B: team_b},
        best_of_sets=3,
        advantage_method="gold_point",
        court=Court.fip_standard(),
        date=datetime(2026, 5, 10, 18, 30),
    )
    match.history.add_point(TeamId.A)
    print(match.history.get_current_score())
    ```

    </CodeGroup>

  </Col>
</Row>

## `set_set_starting_server()` {{ tag: 'method', label: 'match.set_set_starting_server()' }}

<Row>
  <Col>

    Designates which [`Player`](/player) in a pair serves first for that team in a specific set (`1`-indexed), validating that `player` belongs to `teams[team_id]`. Delegates directly to `history.set_set_starting_server()`.

    ### Arguments
    <Properties>
      <Property name="set_index" type="int">
        1-based set number (`1`, `2`, `3`, ...).
      </Property>
      <Property name="team_id" type="TeamId">
        Team identifier (`TeamId.A` or `TeamId.B`).
      </Property>
      <Property name="player" type="Player">
        Player within `teams[team_id]` who will serve the team's opening game in that set.
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Override Set 2 Server" tag="method" label="set_set_starting_server">

    ```python
    from padelkit import Match, Player, Team, TeamId

    p1, p2 = Player("Coello"), Player("Tapia")
    p3, p4 = Player("Galan"), Player("Chingotto")
    match = Match(
        teams={
            TeamId.A: Team(TeamId.A, p1, p2),
            TeamId.B: Team(TeamId.B, p3, p4),
        }
    )
    match.set_set_starting_server(2, TeamId.A, p2)
    ```

    </CodeGroup>

  </Col>
</Row>

## Serialization (`to_dict` / `from_dict`) {{ tag: 'method', label: 'dict I/O' }}

<Row>
  <Col>

    Losslessly serializes `teams`, `config`, `points_history`, `duration_minutes`, `date` (ISO 8601), and `court` into a plain JSON-friendly dictionary (`match.to_dict()`), and replays the complete match state via `Match.from_dict(data)`.

  </Col>
  <Col sticky>

    <CodeGroup title="Dictionary Round-Trip" tag="method" label="to_dict / from_dict">

    ```python
    from padelkit import Match, TeamId

    m = Match(advantage_method="gold_point")
    m.history.add_point(TeamId.A)
    restored = Match.from_dict(m.to_dict())
    assert str(restored.history.get_current_score()) == str(m.history.get_current_score())
    ```

    </CodeGroup>

  </Col>
</Row>
