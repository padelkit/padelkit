# BallState

`BallState` is a frozen dataclass storing the instantaneous **9-Dimensional kinematic state** of a padel ball: 3D position (`m`), 3D linear velocity (`m/s`), and 3D angular spin (`rad/s`). Import via `from padelkit import BallState`. {{ className: 'lead' }}

Whenever you launch a shot from scratch, prefer [`BallState.from_shot()`](#from-shot) so you can specify intuitive `topspin_rpm` and `sidespin_rpm` without computing angular spin axis vectors manually.

---

## Parameters & Fields {{ tag: 'dataclass', label: 'BallState' }}

<Row>
  <Col>

    All vectors must have length `3` (validating in `__post_init__`).

    <Properties>
      <Property name="position" type="tuple[float, float, float]">
        3D ball center position `(x, y, z)` in court meters. Defaults to `(0.0, 0.0, 1.0)`.
      </Property>
      <Property name="velocity" type="tuple[float, float, float]">
        3D linear velocity `(vx, vy, vz)` in `m/s`. Defaults to `(0.0, 0.0, 0.0)`.
      </Property>
      <Property name="angular_velocity" type="tuple[float, float, float]">
        3D angular spin vector `(wx, wy, wz)` in `rad/s` following the right-hand rule. Defaults to `(0.0, 0.0, 0.0)`.
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Initialization" tag="dataclass" label="BallState">

    ```python
    from padelkit import BallState

    ball = BallState(
        position=(0.0, -5.0, 1.8),
        velocity=(1.5, 16.0, 2.0),
        angular_velocity=(-150.0, 0.0, 0.0),
    )
    print(f"Speed: {ball.speed_kmh:.1f} km/h | Spin: {ball.spin_rpm:.0f} RPM")
    ```

    </CodeGroup>

  </Col>
</Row>

## `from_shot()` {{ tag: 'classmethod', label: 'BallState.from_shot()' }}

<Row>
  <Col>

    Constructs a `BallState` by decomposing intuitive `topspin_rpm` (around the horizontal axis perpendicular to flight direction) and `sidespin_rpm` (around `+Z`) into exact 3D `(wx, wy, wz)` angular velocity in `rad/s`.

    ### Arguments
    <Properties>
      <Property name="position" type="tuple[float, float, float] | Sequence[float]">
        Initial 3D ball coordinates `(x, y, z)` in meters.
      </Property>
      <Property name="velocity" type="tuple[float, float, float] | Sequence[float]">
        Initial 3D linear velocity `(vx, vy, vz)` in `m/s`.
      </Property>
      <Property name="topspin_rpm" type="float">
        Transverse spin in RPM: positive values (`+2500`) give **topspin** (downward Magnus dive); negative values (`-1800`) give **backspin / slice** (upward lift & low glass skid). Defaults to `0.0`.
      </Property>
      <Property name="sidespin_rpm" type="float">
        Vertical-axis spin in RPM (`+Z`) for curving *víbora* or sliced serves. Defaults to `0.0`.
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Create Shot with Spin" tag="classmethod" label="from_shot">

    ```python
    from padelkit import BallState

    bandeja = BallState.from_shot(
        position=(-2.5, -2.0, 2.3),
        velocity=(3.5, 16.0, -2.5),
        topspin_rpm=-1800.0,
        sidespin_rpm=400.0,
    )
    print("vector_9d:", bandeja.vector_9d.round(2))
    ```

    </CodeGroup>

  </Col>
</Row>

## `from_vector()` & `to_dict()` {{ tag: 'classmethod', label: 'Vector & Dict I/O' }}

<Row>
  <Col>

    - **`BallState.from_vector(vec)`**: Classmethod accepting any 6-element (`[x,y,z, vx,vy,vz]`, spin defaults to zero) or 9-element vector and returning a `BallState`.
    - **`ball.to_dict()`**: Serializes `position`, `velocity`, `angular_velocity`, `speed_ms`, `speed_kmh`, and `spin_rpm` into a plain dictionary.

  </Col>
  <Col sticky>

    <CodeGroup title="Vector Conversion" tag="classmethod" label="from_vector">

    ```python
    import numpy as np
    from padelkit import BallState

    s = BallState.from_vector(np.array([0.0, -4.0, 2.0, 1.0, 15.0, -1.0]))
    print(s.to_dict())
    ```

    </CodeGroup>

  </Col>
</Row>
