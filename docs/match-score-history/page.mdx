# MatchScoreHistory

`MatchScoreHistory` is the core **Event Sourcing engine** for padel scoring. Rather than storing mutable counters, it appends every won point (`TeamId.A` or `TeamId.B`) to an internal chronological ledger and deterministically recalculates the full [`MatchScore`](/match-score) snapshot on demand. Import via `from padelkit import MatchScoreHistory`. {{ className: 'lead' }}

Class constant `POINTS_SEQUENCE = [0, 15, 30, 40]` defines standard game progression.

---

## Constructor {{ tag: 'constructor', label: 'MatchScoreHistory' }}

<Row>
  <Col>

    Accepts either a pre-built [`MatchConfiguration`](/match-configuration) (`config`) or individual format keyword arguments, plus an optional `teams` dictionary.

    <Properties>
      <Property name="teams" type="dict[TeamId, Team] | None">
        Optional competing pairs keyed by `TeamId.A` and `TeamId.B`. Validated to ensure matching `team.id` keys and unique player names across both pairs. Defaults to `None`.
      </Property>
      <Property name="best_of_sets" type="int">
        Total maximum sets (positive odd integer). Defaults to `3`.
      </Property>
      <Property name="advantage_method" type="str">
        `"advantage"` (default) or `"gold_point"`.
      </Property>
      <Property name="set_format" type="str">
        `"standard"` (6 games, default) or `"mini"` (4 games).
      </Property>
      <Property name="deciding_set_format" type="str">
        `"regular"` (default), `"tiebreak"`, or `"super_tiebreak"`.
      </Property>
      <Property name="starting_server_team" type="TeamId">
        Team serving Game 1 of Set 1 (`TeamId.A` default or `TeamId.B`).
      </Property>
      <Property name="set_starting_servers" type="dict[int, dict[TeamId, Player]] | None">
        Optional per-set opening server overrides. Defaults to `None`.
      </Property>
      <Property name="config" type="MatchConfiguration | None">
        Optional pre-built [`MatchConfiguration`](/match-configuration) overriding individual format flags. Defaults to `None`.
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Initialization" tag="constructor" label="MatchScoreHistory">

    ```python
    from padelkit import MatchScoreHistory, TeamId

    history = MatchScoreHistory(
        best_of_sets=3,
        advantage_method="gold_point",
        starting_server_team=TeamId.A,
    )
    ```

    </CodeGroup>

  </Col>
</Row>

## `add_point()` {{ tag: 'method', label: 'history.add_point()' }}

<Row>
  <Col>

    Appends the winner of the next point (`TeamId.A` or `TeamId.B`) to the point history, replays state progression, and returns the updated [`MatchScore`](/match-score). Points added after the match is already won are ignored during score evaluation.

    ### Arguments
    <Properties>
      <Property name="team" type="TeamId">
        Team that won the point (`TeamId.A` or `TeamId.B`).
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Record Points" tag="method" label="add_point">

    ```python
    from padelkit import MatchScoreHistory, TeamId

    h = MatchScoreHistory()
    score = h.add_point(TeamId.A)
    print(score.points_A, "-", score.points_B)  # 15 - 0
    ```

    </CodeGroup>

  </Col>
</Row>

## `modify_point()` {{ tag: 'method', label: 'history.modify_point()' }}

<Row>
  <Col>

    Overwrites the winner of a previously recorded point at 0-based `index` and immediately recomputes the entire match score, server sequence, tiebreaks, and side changes from scratch.

    ### Arguments
    <Properties>
      <Property name="index" type="int">
        0-based chronological index of the point to correct (`0 <= index < total_points`). Raises `IndexError` if out of range.
      </Property>
      <Property name="team" type="TeamId">
        Corrected winning team (`TeamId.A` or `TeamId.B`).
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Correct Historical Point" tag="method" label="modify_point">

    ```python
    from padelkit import MatchScoreHistory, TeamId

    h = MatchScoreHistory()
    h.add_point(TeamId.A)
    h.add_point(TeamId.A)  # typo: actually won by Team B
    corrected = h.modify_point(1, TeamId.B)
    print(corrected.points_A, "-", corrected.points_B)  # 15 - 15
    ```

    </CodeGroup>

  </Col>
</Row>

## `get_current_score()` {{ tag: 'method', label: 'history.get_current_score()' }}

<Row>
  <Col>

    Replays the event ledger from start to finish and returns the active immutable [`MatchScore`](/match-score) snapshot without mutating history.

  </Col>
  <Col sticky>

    <CodeGroup title="Read Current Snapshot" tag="method" label="get_current_score">

    ```python
    from padelkit import MatchScoreHistory, TeamId

    h = MatchScoreHistory()
    h.add_point(TeamId.B)
    snap = h.get_current_score()
    print(snap)
    ```

    </CodeGroup>

  </Col>
</Row>

## `set_set_starting_server()` {{ tag: 'method', label: 'history.set_set_starting_server()' }}

<Row>
  <Col>

    Designates which player on `team_id` serves first when `team_id` begins serving in set `set_index` (1-indexed). Raises `ValueError` if `teams` is configured and `player` does not belong to `teams[team_id]`.

    ### Arguments
    <Properties>
      <Property name="set_index" type="int">
        1-based set number (`1`, `2`, `3`, ...).
      </Property>
      <Property name="team_id" type="TeamId">
        Team identifier (`TeamId.A` or `TeamId.B`).
      </Property>
      <Property name="player" type="Player">
        Starting server belonging to `teams[team_id]`.
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Assign Set Opener" tag="method" label="set_set_starting_server">

    ```python
    from padelkit import MatchScoreHistory, Player, Team, TeamId

    p1, p2 = Player("Coello"), Player("Tapia")
    h = MatchScoreHistory(teams={TeamId.A: Team(TeamId.A, p1, p2)})
    h.set_set_starting_server(1, TeamId.A, p2)
    ```

    </CodeGroup>

  </Col>
</Row>
