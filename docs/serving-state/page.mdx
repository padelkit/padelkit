# ServingState

`ServingState` is a frozen dataclass capturing who is serving, who is returning, and which diagonal service box is active on the current point. Attached automatically to `MatchScore.server` by [`ServingEngine`](/serving-engine). Import via `from padelkit import ServingState`. {{ className: 'lead' }}

## Parameters & Fields {{ tag: 'dataclass', label: 'ServingState' }}

<Row>
  <Col>

    <Properties>
      <Property name="team" type="TeamId">
        Team currently serving (`TeamId.A` or `TeamId.B`).
      </Property>
      <Property name="player" type="Player | None">
        Specific [`Player`](/player) delivering the serve (`None` when `MatchScoreHistory` runs without `teams`). Defaults to `None`.
      </Property>
      <Property name="receiver" type="Player | None">
        Opposing [`Player`](/player) diagonally returning the serve based on `Player.side` (`None` when `teams` omitted). Defaults to `None`.
      </Property>
      <Property name="court_side" type='Literal["left", "right"] | None'>
        Active service box diagonal: `"right"` (deuce court on even points `0`, `30`) or `"left"` (ad court on odd points `15`, `40`). Defaults to `None`.
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Inspect MatchScore.server" tag="dataclass" label="ServingState">

    ```python
    from padelkit import Match, TeamId

    match = Match()
    score = match.history.add_point(TeamId.A)  # now at 15-0 (odd point -> left box)
    print(score.server.team, score.server.player.name, score.server.court_side)
    # TeamId.A Player 1 left
    ```

    </CodeGroup>

  </Col>
</Row>

## Serialization (`to_dict` / `from_dict`) {{ tag: 'method', label: 'dict I/O' }}

<Row>
  <Col>

    Exports `team`, `player`, `receiver`, and `court_side` (`state.to_dict()`) and restores an identical `ServingState` (`ServingState.from_dict(data)`).

  </Col>
  <Col sticky>

    <CodeGroup title="Dictionary Round-Trip" tag="method" label="to_dict / from_dict">

    ```python
    from padelkit import Player, ServingState, TeamId

    state = ServingState(
        team=TeamId.A,
        player=Player("Coello"),
        receiver=Player("Galan"),
        court_side="right",
    )
    assert ServingState.from_dict(state.to_dict()) == state
    ```

    </CodeGroup>

  </Col>
</Row>
