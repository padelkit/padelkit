# CourtDimensions

The `CourtDimensions` frozen dataclass stores the 11 official physical measurements of a padel court in **meters**. Import via `from padelkit import CourtDimensions`. {{ className: 'lead' }}

<Schematic

## Parameters & Fields {{ tag: 'dataclass', label: 'CourtDimensions' }}

<Row>
  <Col>

    The first 7 geometric fields define the court's primary envelope and have no dataclass defaults (or use [`CourtDimensions.fip_standard()`](#fip_standard) to populate official numbers automatically), while the 4 FIP marking/clearance fields include official defaults.

    <Properties>
      <Property name="length" type="float">
        Total interior length of the court along the Y axis in meters (FIP official: `20.0 m ± 0.5%`).
      </Property>
      <Property name="width" type="float">
        Total interior width of the court along the X axis in meters (FIP official: `10.0 m ± 0.5%`).
      </Property>
      <Property name="net_height_center" type="float">
        Net height at the center strap (`X = 0.0`) in meters (FIP official: `0.88 m ± 0.005 m`).
      </Property>
      <Property name="net_height_posts" type="float">
        Net height at the side posts (`X = ±width/2`) in meters (FIP official max: `0.92 m`).
      </Property>
      <Property name="service_line_distance_from_back" type="float">
        Distance measured from each back wall inward to its service line in meters (FIP official: `3.0 m`, i.e. `6.95 m` from the net center).
      </Property>
      <Property name="back_wall_height" type="float">
        Total height of both back walls (3.0 m solid + 1.0 m mesh) in meters (FIP official: `4.0 m`).
      </Property>
      <Property name="side_wall_height" type="float">
        Height of the side enclosure across the central `16.0 m` in meters: `3.0 m` for `EnclosureVariant.V1` or `4.0 m` for `EnclosureVariant.V2`.
      </Property>
      <Property name="line_width" type="float">
        Painted width of all service and central lines in meters. Defaults to `0.05` m (`5 cm`).
      </Property>
      <Property name="service_line_extension" type="float">
        Extension of the central service dividing line beyond each service line toward the back wall in meters. Defaults to `0.20` m (`20 cm`).
      </Property>
      <Property name="net_post_height" type="float">
        Maximum structural height of the exterior net posts in meters. Defaults to `1.05` m.
      </Property>
      <Property name="free_height" type="float">
        Minimum obstacle-free overhead clearance above the entire playing floor in meters. Defaults to `6.0` m (or `8.0` m for new constructions).
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Initialization" tag="dataclass" label="CourtDimensions">

    ```python
    from padelkit import CourtDimensions

    dims = CourtDimensions(
        length=20.0,
        width=10.0,
        net_height_center=0.88,
        net_height_posts=0.92,
        service_line_distance_from_back=3.0,
        back_wall_height=4.0,
        side_wall_height=3.0,
    )
    print(dims.line_width, dims.free_height)
    # 0.05 6.0
    ```

    </CodeGroup>

  </Col>
</Row>

## `fip_standard()` {{ tag: 'classmethod', label: 'CourtDimensions.fip_standard()' }}

<Row>
  <Col>

    Creates standard FIP official court dimensions parameterized by lateral enclosure variant (`V1` vs `V2`) and minimum overhead clearance (`6.0 m` existing vs `8.0 m` new construction).

    ### Arguments
    <Properties>
      <Property name="variant" type="EnclosureVariant">
        Lateral mesh height variant: `EnclosureVariant.V1` (`3.0 m` central height) or `EnclosureVariant.V2` (`4.0 m` uniform height). Defaults to `EnclosureVariant.V1`.
      </Property>
      <Property name="new_construction" type="bool">
        When `True`, sets `free_height = 8.0` m instead of the `6.0` m regulatory baseline. Defaults to `False`.
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Standard FIP Presets" tag="classmethod" label="fip_standard">

    ```python
    from padelkit import CourtDimensions, EnclosureVariant

    v1 = CourtDimensions.fip_standard()
    v2_new = CourtDimensions.fip_standard(
        variant=EnclosureVariant.V2,
        new_construction=True,
    )
    print(v1.side_wall_height, v1.free_height)      # 3.0 6.0
    print(v2_new.side_wall_height, v2_new.free_height)  # 4.0 8.0
    ```

    </CodeGroup>

  </Col>
</Row>

## `fip_variant_2()` {{ tag: 'classmethod', label: 'CourtDimensions.fip_variant_2()' }}

<Row>
  <Col>

    Convenience factory equivalent to `CourtDimensions.fip_standard(variant=EnclosureVariant.V2, new_construction=...)`, setting a uniform `4.0 m` perimeter height along the full `20.0 m` court length.

    ### Arguments
    <Properties>
      <Property name="new_construction" type="bool">
        When `True`, sets `free_height = 8.0` m; otherwise `6.0` m. Defaults to `False`.
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Variant 2 Shorthand" tag="classmethod" label="fip_variant_2">

    ```python
    from padelkit import CourtDimensions

    v2 = CourtDimensions.fip_variant_2()
    print(v2.side_wall_height)  # 4.0
    ```

    </CodeGroup>

  </Col>
</Row>

## Serialization (`to_dict` / `from_dict`) {{ tag: 'method', label: 'dict I/O' }}

<Row>
  <Col>

    Converts all 11 dimension measurements to a plain JSON-serializable dictionary (`dims.to_dict()`) or reconstructs a `CourtDimensions` dataclass (`CourtDimensions.from_dict(data)`), filling omitted keys from FIP standard defaults.

  </Col>
  <Col sticky>

    <CodeGroup title="Dictionary Round-Trip" tag="method" label="to_dict / from_dict">

    ```python
    from padelkit import CourtDimensions

    dims = CourtDimensions.fip_standard()
    restored = CourtDimensions.from_dict(dims.to_dict())
    assert restored == dims
    ```

    </CodeGroup>

  </Col>
</Row>
