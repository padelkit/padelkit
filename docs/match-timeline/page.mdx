# MatchTimeline

`MatchTimeline` is the universal temporal state container connecting physics trajectories, camera reconstructions, scoring progression, 3D skeletal pose baking, and Apache Parquet / CSV / DataFrame serialization. Import via `from padelkit import MatchTimeline`. {{ className: 'lead' }}

Class constants: `PLAYER_IDS = ("P1", "P2", "P3", "P4")`, `PARQUET_METADATA_KEY = b"padelkit_metadata"`, `SCHEMA_VERSION = "1.0.0"`. Calling `len(timeline)` returns the number of frames.

---

## Constructor {{ tag: 'constructor', label: 'MatchTimeline' }}

<Row>
  <Col>

    <Properties>
      <Property name="frames" type="list[FrameState] | None">
        Ordered list of [`FrameState`](/frame-state) snapshots. Defaults to `None` (empty timeline).
      </Property>
      <Property name="fps" type="float">
        Sampling rate in frames per second (`> 0.0`). Defaults to `60.0`.
      </Property>
      <Property name="court" type="Court | None">
        Venue [`Court`](/court) geometry (falls back to `match.court` or `Court.fip_standard()`).
      </Property>
      <Property name="environment" type="EnvironmentConditions | None">
        Atmospheric [`EnvironmentConditions`](/environment-conditions) (defaults to `EnvironmentConditions.standard()`).
      </Property>
      <Property name="ball_properties" type="BallProperties | None">
        Ball physical specs [`BallProperties`](/ball-properties) (defaults to `BallProperties.fip_standard()`).
      </Property>
      <Property name="surface_materials" type="SurfaceMaterials | None">
        Court [`SurfaceMaterials`](/surface-materials) coefficients (defaults to `SurfaceMaterials.fip_standard()`).
      </Property>
      <Property name="match" type="Match | None">
        Optional [`Match`](/match) containing players, scoring configuration, and point history. Defaults to `None`.
      </Property>
      <Property name="metadata" type="dict[str, Any] | None">
        Optional user-defined JSON-serializable metadata dictionary. Defaults to `None`.
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Initialization" tag="constructor" label="MatchTimeline">

    ```python
    from padelkit import Court, FrameState, MatchTimeline

    tl = MatchTimeline(
        frames=[FrameState(timestamp=0.0, ball_position=(0.0, -4.0, 1.5))],
        fps=60.0,
        court=Court.fip_standard(),
    )
    print(len(tl), tl.fps)  # 1 60.0
    ```

    </CodeGroup>

  </Col>
</Row>

## Properties {{ tag: 'property', label: 'Timeline Telemetry' }}

<Properties>
  <Property name="duration_seconds" type="float">
    Total span in seconds (`frames[-1].timestamp - frames[0].timestamp`, or `0.0` if empty).
  </Property>
  <Property name="has_skeletal_poses" type="bool">
    `True` if any [`PlayerPose`](/player-pose) in any frame contains 17-joint `keypoints_3d`.
  </Property>
</Properties>

## `demo_rally()` {{ tag: 'classmethod', label: 'MatchTimeline.demo_rally()' }}

<Row>
  <Col>

    Synthesizes a multi-shot 3D padel rally driven by [`BallPhysicsEngine`](/ball-physics-engine) with realistic player court positioning, swing anticipation phases, and optional 17-joint H36M skeletons.

    ### Arguments
    <Properties>
      <Property name="court" type="Court | None">
        Court geometry for physics rebounds. Defaults to `Court.fip_standard()`.
      </Property>
      <Property name="fps" type="float">
        Sampling rate in frames per second. Defaults to `60.0`.
      </Property>
      <Property name="environment" type="EnvironmentConditions | None">
        Optional atmospheric conditions (`EnvironmentConditions.standard()` default).
      </Property>
      <Property name="ball_properties" type="BallProperties | None">
        Optional ball parameters (`BallProperties.fip_standard()` default).
      </Property>
      <Property name="surface_materials" type="SurfaceMaterials | None">
        Optional surface materials (`SurfaceMaterials.fip_standard()` default).
      </Property>
      <Property name="match" type="Match | None">
        Optional [`Match`](/match) context (defaults to an auto-created 2v2 match with Coello/Tapia vs. Galan/Chingotto).
      </Property>
      <Property name="bake_skeleton" type="bool">
        When `True`, automatically runs [`bake_skeletal_poses()`](#bake-skeletal-poses) so every player frame carries 17-joint H36M coordinates. Defaults to `False`.
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Generate Physics Demo Rally" tag="classmethod" label="demo_rally">

    ```python
    from padelkit import MatchTimeline

    rally = MatchTimeline.demo_rally(fps=60.0, bake_skeleton=True)
    print(f"Frames: {len(rally)} | Duration: {rally.duration_seconds:.2f}s")
    print("Has 3D skeletons:", rally.has_skeletal_poses)  # True
    ```

    </CodeGroup>

  </Col>
</Row>

## `bake_skeletal_poses()` {{ tag: 'method', label: 'timeline.bake_skeletal_poses()' }}

<Row>
  <Col>

    Populates `keypoints_3d` (`17` H36M local 3D joints) inside every [`PlayerPose`](/player-pose) across the timeline, modifying `self.frames` in place and returning `self` for chaining.

    If `kinematics_dir` is provided (e.g. `"data/kinematics_3d"`), MotionBERT `*_X3D_norm.npy` clips are sampled and phase-aligned at shot impact; otherwise smooth procedural 17-joint poses are synthesized automatically for all stroke types (`idle`, `run`, `serve`, `shot_forehand`, `shot_backhand`, `shot_volley`, `shot_bandeja`, `shot_vibora`, `shot_lob`, `shot_smash`).

    ### Arguments
    <Properties>
      <Property name="kinematics_dir" type="str | Path | None">
        Optional directory holding `*_X3D_norm.npy` 3D skeleton sequences. Defaults to `None` (procedural synthesis).
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Bake 17-Joint Skeletons" tag="method" label="bake_skeletal_poses">

    ```python
    from padelkit import MatchTimeline

    tl = MatchTimeline.demo_rally(bake_skeleton=False)
    tl.bake_skeletal_poses(kinematics_dir=None)
    assert tl.has_skeletal_poses is True
    ```

    </CodeGroup>

  </Col>
</Row>

## `append()` & `build_metadata_envelope()` {{ tag: 'method', label: 'Timeline Building' }}

<Row>
  <Col>

    - **`append(frame)`**: Appends a [`FrameState`](/frame-state) snapshot to `self.frames`.
    - **`build_metadata_envelope()`**: Builds the JSON dictionary embedded into Parquet headers (`schema_version`, `fps`, `duration_seconds`, `frame_count`, `has_skeletal_poses`, `joint_names`, `court`, `environment`, `ball_properties`, `surface_materials`, `match`, `metadata`).

  </Col>
  <Col sticky>

    <CodeGroup title="Inspect Metadata Envelope" tag="method" label="build_metadata_envelope">

    ```python
    from padelkit import FrameState, MatchTimeline

    tl = MatchTimeline()
    tl.append(FrameState(timestamp=0.0, ball_position=(0.0, 0.0, 1.0)))
    env = tl.build_metadata_envelope()
    print(env["schema_version"], len(env["joint_names"]))  # 1.0.0 17
    ```

    </CodeGroup>

  </Col>
</Row>

## `to_parquet()` & `from_parquet()` {{ tag: 'method', label: 'Universal Parquet I/O' }}

<Row>
  <Col>

    - **`timeline.to_parquet(path, compression="zstd", include_skeleton=True)`**: Serializes both frame columns (including the `204` 3D joint columns when `include_skeleton=True` and `has_skeletal_poses` is `True`) and the `padelkit_metadata` Arrow schema header into one compressed `.parquet` file, returning `Path`.
    - **`MatchTimeline.from_parquet(path, court=None)`**: Classmethod restoring the full `MatchTimeline` and embedded `Court`, `EnvironmentConditions`, `BallProperties`, `SurfaceMaterials`, and `Match` objects from disk.

    *(See [Universal Match Format](/match-format) for the complete column and metadata specification.)*

  </Col>
  <Col sticky>

    <CodeGroup title="Save & Load Parquet" tag="method" label="to_parquet / from_parquet">

    ```python
    from padelkit import MatchTimeline

    tl = MatchTimeline.demo_rally(bake_skeleton=True)
    tl.to_parquet("rally.parquet", compression="zstd", include_skeleton=True)

    loaded = MatchTimeline.from_parquet("rally.parquet")
    assert len(loaded) == len(tl) and loaded.has_skeletal_poses
    ```

    </CodeGroup>

  </Col>
</Row>

## `to_dataframe()`, `to_csv()`, `from_dataframe()` & `from_csv()` {{ tag: 'method', label: 'Tabular & Dict I/O' }}

<Row>
  <Col>

    - **`to_dataframe(include_skeleton=True)`**: Exports frames as a `pandas.DataFrame` (`51` base columns, or `255` with 3D skeletons).
    - **`to_csv(path, include_skeleton=False)`**: Writes CSV to `path` and returns `Path`.
    - **`from_dataframe(df, court=None, fps=None, environment=None, ball_properties=None, surface_materials=None, match=None, metadata=None)`**: Classmethod reconstructing a `MatchTimeline` from any DataFrame containing at least `timestamp`, `ball_x`, `ball_y`, `ball_z`.
    - **`from_csv(path, court=None)`**: Classmethod loading a CSV file directly via `from_dataframe()` (infers `fps` automatically from timestamps).
    - **`to_dict()`**: Exports timeline metadata and all serialized frames as a JSON-friendly dictionary.

  </Col>
  <Col sticky>

    <CodeGroup title="CSV & DataFrame Round-Trip" tag="method" label="to_dataframe / from_csv">

    ```python
    from padelkit import MatchTimeline

    tl = MatchTimeline.demo_rally()
    df = tl.to_dataframe(include_skeleton=False)
    tl.to_csv("rally.csv", include_skeleton=False)

    reloaded = MatchTimeline.from_csv("rally.csv", court=tl.court)
    assert len(reloaded) == len(tl)
    ```

    </CodeGroup>

  </Col>
</Row>
